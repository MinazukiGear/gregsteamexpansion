# Greg Steam Expansion v0.1.0-alpha.5

这是面向测试的 Alpha 预发布版本，集中补齐大型蒸汽生产链、运行状态持久化和自动化边界。

## 新增与改进

- 加入大型蒸汽供给仓：容量 `256,000 mB`，单次最多原子供给 `4,800 mB/t`，并提供由普通供给仓、青铜桶和 HV 电路组成的升级路线。
- 大型蒸汽机器支持可切换超频：配方耗时减半并向上取整，每刻蒸汽消耗变为三倍；当前批次会锁定启动时的设置。
- 完善大型蒸汽高炉的完整生产闭环，包括铁粉制锻铁、锻铁炼钢、鼓风供应、96 并行和多结构共享墙体。
- 完善大型蒸汽组装机与电路组装机的结构、槽位阶梯、并行、蒸汽经济和焊锡流体输入。
- 增加结构诊断与 Jade 状态数据，使缺块、仓室数量和运行受阻原因更容易定位。

## 修复

- 控制器的批次、进度、待输出、输入来源和超频状态可在区块重载及服务器重启后正确恢复。
- 处理机可正确结算流体产物，并按全部产物竞争同一剩余容量，避免完成时丢失或重复产物。
- 蓄热蒸汽熔炉按独立输入总线选择配方，避免跨总线拼接材料，并持久化轮询位置。
- 旧蒸汽供给仓迁移时保留蒸汽、朝向、染色、工作状态和覆盖板；迁移失败会完整回滚。
- 控制器被拆除时会掉落尚未交付的物品产物，并防止仓室库存被复制。

## 验证状态

- 137 项 GameTest 全部通过，其中 50 项覆盖蒸汽机器运行与边界。
- Easy、Normal、Expert 三档均在独立 JVM 中通过完整的 137 项 GameTest，原配置在测试后恢复。
- 生成资产检查通过：87 项资产保持最新；语言键 693 项、Jade UID 11 项均通过门禁。
- `check` 与发布构建通过。
- 用户已在 Expert 开发客户端中验收大型蒸汽组装机与大型蒸汽电路组装机的生存链衔接、结构、槽位、界面和实际运行主路径。

## 测试阶段说明

本版本仍处于测试阶段。尚未逐项反馈的旧世界迁移、异常状态、外部接口组合和其余机器详细验收仍保留在设计清单中。内容、数值、资源 ID、存档格式与接口仍可能调整，请勿用于重要存档。

运行需要 Minecraft 1.20.1、Forge 47.4.10 和 GregTech CEu Modern 7.5.3。
