# Greg Steam Expansion v0.1.0-alpha.6

## 难度权威接口

- 新增单一启动期外部难度提供者接口，允许 GTSF Core 在首次数据包加载前提交有效档位与完整 profile。
- 外部权威存在时，GSE 自有开关、档位、首次选择标记及三档 profiles 不参与运行；GSE 独立安装行为保持原样。
- 联机声明、客户端同步、机器倍率、GTCEu 配方预设和数据包条件统一读取有效启动快照。
- 外部权威下跳过首次选择页，Mods 配置页将难度显示为只读，同时保留终极终端等非难度入口。
- GTSF Core 将最低 GSE 版本同步提升至本版本。

## 验证

- `compileJava` 与 jar 重混淆构建通过。
- GTSF Core 使用三组互相冲突的包核/GSE 配置，在三个独立 GameTest JVM 中验证 Easy、Normal、Expert 均只采用包核档位与 profile。
