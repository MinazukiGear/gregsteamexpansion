# Greg Steam Expansion 0.1.0-beta.2 开发记录

日期：2026-10-09。当前为本地开发版，尚未发布；Minecraft 1.20.1、Forge 47.4.10、GTCEu Modern 7.5.3、JDK 17。此次不新增机器或外挂，不调整机器经济。

## 终端修复与交互

- 全服方块预算在活动工程间共享。小预算轮换所有者；离线、跨维度、未加载及失败或完成工程未用掉的额度分配给其他可施工工程。
- 目标页与预览页加入取消队列，只在任务运行或暂停时可用。取消按原材料事务与归属日志回滚当前目标，保留已完成目标、外部修改、方块实体和未加载位置；未用材料与合法回滚材料退还，空间不足时进入持久待领取清单。
- 已取消状态可保存恢复并重新规划；重复取消和领取不会重复退款。拆除取消只停止后续操作，并交付已经拆下的材料。
- 放置/拆除失败及最终结构核验失败改为中英文说明，取消按钮提供回滚范围提示。

工程数据字段版本仍为 `7`，旧状态枚举序号保持不变，取消状态追加在末尾；网络协议为 `7`，客户端和服务端需使用相同版本。调度游标仅存在运行期，服务器重启后重新轮转，不影响已保存任务进度或材料。

## 验证与文档

- 接续已有跨平台工作：固定 ForgeGradle、统一 Python 完整门禁、资源路径/UTF-8/模型引用和 Java 17 JAR 检查；CI 保留四个 OS/架构组合。
- 数据生成新鲜度按运行前后资源内容检查，保留已有开发修改；新增故障夹具确认新增、修改、删除生成资源会失败，`.cache` 不影响判定。
- 每轮验证先将旧测试世界归档到 `build/verification/world-history/`，防止测试布局变化后旧结构与归属日志干扰；配置保留，重启测试的 seed/verify 仍共享同一新世界。
- 新增四项 GameTest，覆盖共享、小预算与连续奇数预算轮转，三人中一人离线/跨维度/未加载时其余玩家等额施工及 NBT 续作，失败后退款重启，取消保留已完成目标与满背包退款恢复。
- 更新设计索引、当前版本与测试数量；成长指南增加默认关闭难度的供汽比较和多人终端操作说明。

原有 187 项回归与新增四项组成当前 191 项套件；修复前新增测试已复现项目独占预算及恢复后继续挤占预算两个问题。最终代码于 2026-10-09 在 Windows 11 x64、Zulu JDK `17.0.13`、Python `3.12.14`、Pillow `12.3.0` 下完成 `python tools/verify.py --offline`，退出码为 `0`，日志末行为 `All gates passed.`。完整日志保存在本地 `.tmp/beta2-confirmation-gate.log`（不提交到仓库）。
