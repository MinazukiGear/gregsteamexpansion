# Greg Steam Expansion 0.1.0-beta.2

[beta.2 预发布](https://github.com/MinazukiGear/gregsteamexpansion/releases/tag/v0.1.0-beta.2)已发布。适用于 Minecraft 1.20.1、Forge 47.4.10 与 GTCEu Modern 7.5.3，使用 Java 17。此次集中修复终极终端、客户端配方显示和开发验证，不新增机器、外挂或生产链，不调整机器经济。

## 更新内容

- 终极终端公平分配全服施工预算，轮换低预算下的工程；离线、跨维度、未加载及已停止工程不再挤占其他工程的可用额度。
- 目标页与预览页增加取消队列。取消施工时回滚当前目标的合法放置，保留已完成目标、外部修改、方块实体及未加载位置；余料和回滚材料退还，容量不足时保留待领取退款。取消拆除时停止后续操作并交付已拆材料。
- 取消状态可保存恢复并重新规划，重复取消和领取不重复退款；施工、拆除及最终核验错误提供中英文说明。
- 修复客户端同步后将已经完成的矿石粉碎配方迁移误报为失败的问题，保持同步后的配方数量与产量。
- EMI 多方块结构预览使用独立虚拟 ID，修复大型焦炉预览与制作配方的 ID 冲突。
- 修复 GuideME 在开发客户端首次资源重载时提前读取配置导致的崩溃；限定单个选项的开发环境早期读取，正式环境保留上游行为。
- 完整验证入口统一为 Python，增加资源与 Java 17 包检查、独立测试世界归档和数据生成内容校验；CI 配置覆盖四个 OS/架构组合。
- 成长指南明确原始高炉首批钢先于高压粉碎机，经济报告补齐默认关闭难度的获取材料与持续供油比较。

## 安装与升级

安装 `gregsteamexpansion-0.1.0-beta.2.jar`；必需前置为 Forge 与 GTCEu Modern。终极终端需要同时安装 AE2（至少 15.4.2）和 GTM Things（至少 1.6.0），并安装它们各自要求的依赖；核心机器可在没有这两项可选模组时加载。EMI、Jade、Modern UI 等开发辅助模组不打包进 GSE。

**客户端与服务器一同升级到 beta.2。** 终极终端网络协议从 beta.1 的 `6` 升为 `7`，不能混用。工程数据版本保持 `7`，旧状态序号不变；升级前备份世界，用副本核对已有机器和终端工程，再替换正式环境。难度集成默认关闭，既有世界升级不要求调整配方或产汽配置。
