# Greg Steam Expansion 0.1.0-beta.1

首个 beta，适用于 Minecraft 1.20.1、Forge 47.4.10 与 GTCEu Modern 7.5.3。
本次发布保留已有开发成果，集中修复、验证和发布，不新增机器、生产链或玩法。

## 修复与整理

- 终极终端在目标控制器拆除、替换或转向后停止原任务，按归属日志回滚本次施工并退还余料。同位置重新放置也会撤销原控制器归属。
- 生存施工的部分取料失败、背包已满、网络拒收和队列失败保留持久退款；回滚核对原方块与放置后完整状态，保护外部修改和方块实体。
- 离线、跨维度和区块卸载暂停保存游标与托管材料，恢复后不重复取料；完成核验遵守不强加载区块的约定。
- 保留已有多面外挂蓝图与稳定 ID 迁移，更新成长指南与三档经济基线。
- 验证世界、配置与可选依赖运行环境独立于开发存档；结构夹具的手动检查使用 GTCEu 图案锁。

工程数据版本为 `7`，兼容读取旧工程；缺少控制器快照的旧队列首次恢复时绑定现存控制器。网络协议为 `6`，客户端与服务器应安装相同版本。

## 发布验证

发布门禁覆盖 187 项 GameTest、双 JVM 存档恢复、Easy / Normal / Expert 配置重启、core / AE2 / full 三种依赖组合、真实 AE 材料事务、数据生成新鲜度、语言与资产一致性、获取配方和经济基线。

执行记录见 [GitHub Actions](https://github.com/MinazukiGear/gregsteamexpansion/actions/workflows/build.yml)，安装包、校验值与最终验证结果见 [v0.1.0-beta.1](https://github.com/MinazukiGear/gregsteamexpansion/releases/tag/v0.1.0-beta.1)。此前 P0 / P2 / P3 文档保留其历史版本和通过数量。

## 安装

安装 `gregsteamexpansion-0.1.0-beta.1.jar`，必需前置为 Forge 与 GTCEu Modern。终极终端需要同时安装 AE2（至少 15.4.2）和 GTM Things（至少 1.6.0）；其余核心机器可在没有这两项可选模组时加载。

这是预发布版本；自动验证覆盖已知故障路径，不能保证所有整合环境中不存在问题。问题反馈请附版本、复现步骤与日志。
