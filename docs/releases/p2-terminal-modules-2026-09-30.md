# P2 终端模块组合施工（2026-09-30）

开发版本：`0.1.0-alpha.6`。根据用户指示，本轮只推进终端多模块组合施工，不设计发酵链或供汽调度，不执行人工验收，不修改机器数值、模块几何或配方。

## 已接入行为

- 按安装面分别选择模块，同面只保留一项，不同面可组合。高炉支持后面热风炉组与顶部加料塔，锅炉房支持五面九项，大型焦炉支持右面干熄焦与底部炉组基座。
- 锅炉房直接提供全部已实现模块目录，可从空地规划；功能仓室由玩家安装，端口坐标仍参与布局检查。
- 配置保存稳定模块 ID，旧单选索引按旧目录迁移。锅炉房保留旧现场过滤目录的解析口径；共享默认索引分别迁移到机器类型模板，避免跨机器改写含义。失效选择保留并阻止启动，玩家可重选或清除。
- 同一蓝图汇总材料与施工。要求一致的主体普通连接点只计一次；不兼容主体约束及跨模块共享位置拒绝施工，即使两个模块要求相同也不允许共用。空气位、控制器和仓室不能作为共用连接点。
- 严格空气坐标随队列保存，恢复施工与目标完成时再次核对。区块未加载时暂停；空气位被占用时停止并回滚当前目标已执行的施工，保留占用方块。旧任务缺少空气字段时继续兼容读取。
- 分槽快照与增量同步已接入；目录与持久槽位均有数量上限。网络协议更新为 `6`，服务端与客户端需使用一致版本。新增安装面、失效选择和模块冲突提示的中英文文本。

权威行为见[终极终端规格](../design/ultimate-terminal.md)，建设顺序见[成长指南](../guides/steam-progression.md)。

## 保留边界

人工验收保持待执行，包括分面下拉栏实际观感、组合全息、生存背包/AE 取料与退还、真实玩家离线和工程跨服务器重启。远程 CI、发布和提交不在本轮执行范围。其他机器候选沿用原有未立项状态，发酵链不开展设计。

旧锅炉房单选配置未保存模块 ID；首次迁移只能重现当前现场的旧过滤目录。若旧索引保存后现场目录已经改变，原身份无法从旧格式唯一恢复，需核对并重选。新 ID 配置不受此限制。
