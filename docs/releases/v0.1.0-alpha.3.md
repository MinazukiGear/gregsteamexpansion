# Greg Steam Expansion v0.1.0-alpha.3

这是面向测试的 Alpha 预发布版本。

## 修复

- 修正蒸汽流体输入仓和蒸汽流体输出仓的模型资源引用，使正面实际加载本项目提供的专用贴图。
- 输入仓与输出仓现在使用轮廓不同、流向相反的箭头标识，便于在多方块结构中直接区分。

## 验证状态

- 全部机器的基础游戏内运行冒烟测试此前已通过。
- 本次修复已通过编译、84 项 GameTest、数据生成一致性检查、生成资产检查和发布构建。

## 测试阶段说明

本版本仍处于测试阶段。完整生存获取与生产闭环、旧存档迁移、区块卸载与重载、断供和堵塞恢复、各档位数值边界及复杂跨模组自动化组合尚未全部验收。内容、数值、资源 ID、存档格式与接口仍可能调整，请勿用于重要存档。

运行需要 Minecraft 1.20.1、Forge 47.4.10 和 GregTech CEu Modern 7.5.3。
