# Greg Steam Expansion v0.1.0-alpha.2

这是面向测试的 Alpha 预发布版本。使用者已确认当前全部机器能够在游戏内正常运行，项目现已进入完整生存流程、存档稳定性、异常恢复和跨模组自动化验证阶段。

## 本版内容

- 完整的蒸汽处理机器家族，包括粉碎、洗矿、研磨、化学浸洗、离心、热力离心、压缩、提取、锻压、搅拌、组装与电路组装。
- 大型蓄热蒸汽熔炉、普通与大型焦炉、大型蒸汽高炉、四档锅炉房，以及大型蒸汽采矿厂和流体钻井。
- 蒸汽供给、排气、流体输入/输出和空气进气仓室体系。
- Easy、Normal、Expert 三档启动期工作强度。
- 标准、创造、ME 与 ME 样板总成多方块自动化接口兼容。
- 结构诊断、Jade 信息显示、EMI 结构预览和中英文文本。

## 验证状态

- 全部机器的基础游戏内运行冒烟测试已通过。
- 当前自动化门禁包含 84 项 GameTest，以及编译、设计契约、生成资产、语言/Jade 键集合与发布构建检查。
- Expert 基础材料、蒸汽供给、蒸汽粉碎、锻铁配方门控和锅炉房详细验收已有记录。

## 测试阶段说明

本版本仍处于测试阶段。完整生存获取与生产闭环、旧存档迁移、区块卸载与重载、断供和堵塞恢复、各档位数值边界及复杂跨模组自动化组合尚未全部验收。内容、数值、资源 ID、存档格式与接口仍可能调整，请勿用于重要存档。

运行需要 Minecraft 1.20.1、Forge 47.4.10 和 GregTech CEu Modern 7.5.3。
