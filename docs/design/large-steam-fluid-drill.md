# 大型蒸汽流体钻井设计

本文档是「大型蒸汽流体钻井」(旗舰系统 F2)的设计文档。**全部 `12` 个设计议题已于 2026-09-08 由用户拍板收口**,无待定项;标"提案值"的数字为起草时给出、待用户复核的量。

### 定位与配置开关(议题 2)

- **虚空产流体终端**:不与任何区块地层、沉积层数据交互,产出来源为纯生成(用户 2026-09-08 拍板议题 3 = a)。
- **配置开关**:`large_steam_fluid_drill_enabled`(默认 `true`,重启生效,与难度配置同口径)。禁用时:注册保持完整、结构与物品可获取,但**机器不可运行**,GUI/状态显示"已在配置中禁用"(用户议题 7 定案)。
- **不是**钻井平台下探:不铺矿杆、不查询地层流体(与 F1 同口径改写)。

### 产出池与概率(议题 3)

- **每次抽取按权重随机独立选出一种主世界流体**(用户议题 3 定案"按概率产出任意一种主世界流体")。
- **默认概率表(提案值,沿用上游 `GTBedrockFluids` 主世界沉积层权重,和 75)**:

| 流体 | 权重 | 上游来源 |
| --- | ---: | --- |
| 轻质原油(Oil Light) | 25 | `LIGHT_OIL` |
| 原油(Oil) | 20 | `OIL` |
| 重质原油(Oil Heavy) | 15 | `HEAVY_OIL` |
| 天然气(Natural Gas) | 15 | `NATURAL_GAS` |

- **排除水与熔岩**(B5 裁决:原版水源已覆盖;熔岩属下界语义)。
- ⚠ **评审裁决点(记录在案)**:天然气与 A5 煤气发生炉撤销裁定的精神存在张力("煤气在热解炉之前不应有获取途径")。本机在蒸汽时代天然气无法精炼(无蒸馏途径),仅作库存积累,但若复核认为其构成燃料类进度门控例外,可从表中移除——移除后权重和 60,其余比例不变。
- 概率表硬编码(v1 不进配置),表格在文档与 GUI 悬浮提示中公示;单次抽取只产一种流体,不混合。

### 结构与外观(议题 4,按建议口径)

- 包围盒 `7×7×11` 井架塔,四个水平朝向;阶梯收顶(热力离心机先例):
  - 第 1 层(底):`7×7` 全工业蒸汽机械方块(**49** 格,含正面底层正中控制器);
  - 第 2–8 层(7 层):`7×7` 环——4 角竖棱工业方块(**28** 格)+ 四面墙体蒸汽机械方块(**20 格/层,共 140**,仓室唯一可替换区);内部 `5×5`:
    - 中轴青铜管道方块柱(`x=4,z=4`,第 2–7 层,**6** 格,钻杆语义);
    - 第 8 层中心蒸汽搅拌方块(**1** 格,气液分离段);
    - 其余内部 **168** 格固定空气;
  - 第 9–10 层:`5×5` 环蒸汽机械方块(**16 格/层,共 32**,可替换),内部 `3×3` 空气 **18** 格;
  - 第 11 层(顶):`3×3` 全工业方块(**9** 格,井架顶冠)。
- 外壳合计:工业 `49 + 28 + 9 = 86`,蒸汽方块 `140 + 32 = 172`,共 **258** 格;中轴 7 格;空气 186 格;总计 451 格 ✓(`7×7×8 + 5×5×2 + 3×3`)。
- 排气仓位于墙体(必须且只能 1 个,大型机规则)。

### 动力与蒸汽消耗(议题 5)

- 仅接受 GTCEu 标准蒸汽,不消耗 EU;**无配方类型**,蒸汽按固定生产节拍结算。
- **2 个泵位**,单泵位节拍 **40 tick** 完成 1 次抽取;单泵位耗汽 **2,000 mB/t**(提案值)。
- 满速(2 泵位并行)= **4,000 mB/t**,需 `ceil(4,000 ÷ 1,200) = 4` 个供给仓——对齐锅炉房产能档(议题 5 用户确认"是")。
- 供汽结算沿用家族口径:逐刻原子取汽、单仓 1,200 mB/t 上限、断汽回退 1 tick 续跑。
- 等效成本(提案值口径):`80,000 mB 汽 / 1,600 mB 流体 = 50:1`(单泵位单抽),约为"消耗蒸汽换流体"的重质成本——流体钻井的价值锚定**无限与位置无关**,不是吞吐(见议题 6)。

### 产量与三档难度(议题 6)

- **产出倍率(用户定案,与 F1 一致的新口径)**:`Easy ×4 / Normal ×2 / Expert ×1`,作用于每次抽取的**流体量**;耗汽、节拍、概率表三档相同。
- 单泵位单抽产流体(提案值):**1,600 mB**(Expert)/ 3,200 mB(Normal)/ 6,400 mB(Easy)。
- 满速产出(2 泵位,提案值):Expert **80 mB/t**、Normal **160 mB/t**、Easy **320 mB/t**——参考:Expert 满速 1 小时 ≈ 288 桶(288,000 mB)。
- 倍率对每次抽取即时生效;正在进行的节拍按启动时档位结算。
- 期望产量:满速每 40 tick 2 次独立抽取,产出分别写入(两种流体不混合,各自找输出空间)。

### 库存与输出(议题 7)

- 控制器无内部流体罐;产物一次性写入流体输出仓(≥1;**GTCEu 标准流体输出仓或本模组蒸汽流体输出仓,可选或混用**,B4/C0 口径——蒸汽流体输出仓在此获得第二个合法消费者)。
- 多种流体并行排队:每次抽取的产物独立提交;输出阻塞则暂停生产节拍(不耗汽),空间恢复后续跑。
- 物品接口:**无**(本机不产出物品;不设任何物品总线)。

### 运行控制与禁用行为(议题 8)

- 标准 GTCEu 启停控制:软锤 + GUI 电源按钮;暂停期间不取汽、不推进。
- 结构失效:进度回退 1 tick,修复后续跑。
- 配置禁用(议题 2/7):优先级最高,机器不启动,状态栏显示"已在配置中禁用"。
- 排气仓:必须且只能 1 个;受阻冻结进度(不回退),反馈脉冲与热伤害沿用通用规则。

### 表现与信息(议题 9)

- GUI 沿用家族运行信息页骨架,新增:
  - **概率表悬浮提示**(完整权重表,中英双语);
  - 泵位状态行:当前节拍剩余 tick、上周期产出摘要(流体 × mB × 2 泵位);
  - 配置禁用时的红色状态行。
- 声效沿用 GTCEu 钻机声(drill,提案值;实现时以可用声效登记为准);泵位推进时叠加水/油花粒子。
- 控制器正面两态纹理走 `steamMultiblockModel` 的 `addTextureOverride` 模式(纹理原创绘制,家族配色)。
- 两级物品提示:结构、概率表、三档倍率、耗汽、禁用行为;中英双语。

### 与既有裁决的关系(议题 11)

- **B5 抽水站撤销**:水被排除出产出池(原版水源已覆盖),裁定完整保留。
- **A5 煤气门控**:天然气条目的张力已记录(议题 3 ⚠),交用户复核裁决;若保留,依据是"蒸汽时代无精炼途径、非燃料链解锁"。
- **多方块储罐**:本机是生产机器不是储罐;无大容量缓存(控制器无内部罐)。
- **冷凝水回收 / 蒸汽涡轮**:不涉及。
- **油类流体与燃料链**:原油类不进本模组锅炉燃料池(`STEAM_BOILER_RECIPES` 无油类),不构成锅炉房自燃料闭环。

### 上游基准(已核对源码)

- `GTBedrockFluids`:主世界沉积层定义(轻油/原油/重油/天然气等),含 weight/yield(100–300 mB/次)/depletionAmount/Chance/depletedYield/biomes/dimensions。
- `LargeMinerMachine`(电力多方块):消耗 DrillingFluid 切换流体模式开采区块沉积层,有耗竭。
- **本机差异(用户定案)**:不读沉积层数据(纯虚空)、不耗竭、无限、不消耗钻井液、不铺矿杆;概率权重沿用上游主世界沉积层权重(50:100:15:25 → 本表 15:20:25:15 归一化前值);单抽量 1,600 mB 高于上游 yield 上限(300 mB/次),由三档倍率体系覆盖。

### 立项前提

1. **定位:旗舰收官**(与 F1 并列的流体侧终章;蒸汽时代获得位置无关的油类来源)。
2. **配置开关是平衡阀**:无限流体产出天然敏感,启用权交给整合包/服务器。
3. **输出仓归宿**:蒸汽流体输出仓获得第二个消费者(F1 无流体接口,不参与)。
