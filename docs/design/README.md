# 设计文档索引与当前状态

状态核对日期：2026-09-14；发布基线：`v0.1.0-alpha.4`。当前处于 Alpha 测试阶段；全部机器的基础游戏内运行冒烟测试已由用户确认通过，主任务转为验证生存获取与生产闭环、存档稳定性、异常恢复和跨模组自动化。工程重构 P0～P2 已完成，历史实现和门禁记录见[工程路线图](../refactor-roadmap.md)。

“已定案”表示设计规则已确认；“已实现”表示已有代码与资源；“基础运行通过”表示机器已在游戏内正常成型或启动并完成其基本工作流程；“已验收”只记录用户实际执行并确认的具体规格。基础运行通过不自动完成存档、异常状态、兼容性和数值边界清单，也不将代码与定案的差异改写为新规则。

## 当前待办

1. 走通“基础材料 → 产汽与供汽 → 矿物处理 → 锻铁/钢 → 零件装配”的生存获取与生产链，记录配方、材料前置和实际供汽瓶颈。
2. 按机器规格核验断汽恢复、输出堵塞、结构拆建、存档重载、档位重启后的机器状态迁移，以及 GUI/Jade、EMI 和外部容器交互；启动期全局难度配置本身已验收。
3. 控制器核心运行状态与待输出的 NBT 往返、处理机真实区块落盘重载和完整服务器进程重启、启动配置跨进程重启、完整流体加工链、多产物竞争剩余容量及结构诊断边界已接入自动化。自动化结果与手动验收分别记录。
4. 继续按原定案核对设计与实现差异；若需改变玩法规则，则独立讨论。当前已发现的静态差异均已收口。

生存链进度（2026-09-14）：第一批 Expert 基础材料工作台路线已验收。工业蒸汽机械方块与青铜构件均可在进入电力时代前按规格合成，工具只损耗耐久，EMI 只显示当前启动档位的配方；Easy、Normal 与组装机路线仍待后续批次验证。第二批蒸汽供给链已验收：新供给仓可正常合成，只接受并缓存最多 `32,000 mB` 标准蒸汽，能把锅炉蒸汽交给多方块执行配方；旧仓从正常入口隐藏且旧仓物品放置时转换。旧方块实体迁移与 `50,000 mB` 超额蒸汽保留现已接入自动化，封面迁移和真实旧世界升级仍待游戏内验证。第三批 Expert 蒸汽粉碎链已验收：蒸汽碾磨方块与控制器可正常获取，`3×3×3` 结构成型并处理矿石方块和粗矿，单并行按 `600 tick`、`200 mB/t` 运行，产物倍率与 EMI 迁移去重符合规格。第四批锻铁配方门控已验收：三条纯粉锻铁路线正确显示，上游原始高炉拒绝执行它们，原有炼钢、熔铁和铁粒锻铁路线不受影响。第五批基础运行冒烟测试由用户确认：全部机器均可在游戏内正常运行；该结果覆盖基本可运行性，不代替尚未逐项记录的获取路线、存档迁移、堵塞恢复、跨模组接口和数值边界验收。
