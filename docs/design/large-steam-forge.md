## 上游基准（已核对源码）

### 配方类型定义（`GTRecipeTypes.FORGE_HAMMER_RECIPES`）

| 字段 | 上游值 |
| --- | --- |
| 配方类型 ID | `gtceu:forge_hammer` |
| 能量方向 | 输入（`ELECTRIC`，`IO.IN`） |
| 物品输入/输出槽 | 最多 `1 / 1` |
| 流体输入/输出槽 | `0 / 0` |
| 构建器默认值 | **无默认 `EU/t` 与耗时**，每条配方自带数值 |
| 进度条 / 声效 | 锻压进度条（自带蒸汽皮肤 `PROGRESS_BAR_HAMMER_STEAM`）、`FORGE_HAMMER` 声 |

### 配方特点（影响本机设计的客观事实）

- 锻压配方是全类型最简的 `1 → 1` 干式工序，但覆盖面广：材料成型（`MaterialRecipeHandler`：锭/粉/板形态处理）、矿石锻碎（`OreRecipeHandler` 的 `ORE_FORGING` 分类，`ore-crushing.md` 已确认保留该路线）、零件锻造（`PartsRecipeHandler`）、电路相关、原木/石头类处理（`VanillaStandardRecipes`、`StoneMachineRecipes`）与机器回收（`MachineRecipeLoader`）。
- 上游电力机器：锻造锤为 LV–UV 单方块。
- **蒸汽锻造锤已存在**（`STEAM_HAMMER`，青铜低压 + 钢高压单方块蒸汽机器）——本机为**规模化上位**定位（A4/C0/C1b/C1a 模式）。
- GCYM 电力多方块**大型材料压制机**（`large_material_press`）同时执行弯曲/压缩/锻造/成型四类型（含 `forge_hammer`）——电力对照物，按 B4/GCYM 先例分层共存。

## 立项前提

1. **定位：规模化上位**（蒸汽锻造锤已存在，A4/C0/C1b/C1a 模式）：锻压工序的批量化与集中自动化。
2. **无电力多方块专属路线冲突**：GCYM 大型材料压制机虽执行 `forge_hammer` 类型，但按能源形态分层共存（B4 先例）。
3. **纯干式最简类型**：`1 → 1`、无流体、无电路——与 C1a 压缩机并列全家族最简输入输出面。
4. **越级模式沿用**：锻造锤属 LV 电力机器，越级使用、以蒸汽消耗为平衡代价、电力路线原样保留。

## 设计议题大纲

以下各节是需要逐项确认的议题清单；每节只列问题，不预设答案。

### 议题 1：身份与注册

- 中文名、英文名、资源 ID、注册字段、机器类（建议：大型蒸汽锻压厂 / Large Steam Forge / `gregsteamexpansion:large_steam_forge` / `LARGE_STEAM_FORGE` / `LargeSteamForgeMachine`；备选 `large_steam_forge_hammer`）。
- 科技阶段定位：建议青铜蒸汽时代后期。

### 议题 2：与既有机器的分工边界

- 仅执行 `gtceu:forge_hammer` 类型，与 GCYM 大型材料压制机（四类型电力多方块）按能源形态分层共存。
- 与蒸汽锻造锤单方块（青铜/钢）：规模化上位关系。
- `ORE_FORGING` 矿石锻碎路线归属：上游保留路线，本机执行与否（`ore-crushing.md` 已确认该路线保留在锻造锤）。
- 与电力锻造锤（LV–UV）沿用越级结论与否。

### 议题 3：配方执行细节

- 全配方开放与外部配方自动可用；是否沿用 **LV 电压门**（C0/C1 家族同款）。
- 纯干式 `1 → 1` 类型说明；基准数值不修改（按配方自带数值换算）。

### 议题 4：结构与外观

- 结构尺寸与逐层布局（待用户给数）；结构方块选型（蒸汽装配方块——锻打夹持语义，B1 已消化该方块、多消费者合法；数量摆位待定）。
- 外壳材质（粉碎机家族青铜口径 / 两区）、仓室口径：物品总线 ≥1、蒸汽供给仓 ≥1、排气仓（大型机严格 `1` 与否）；无流体仓。
- 控制器位置、结构共用口径沿用与否。

### 议题 5：动力与蒸汽消耗

- 换算率 `2 mB = 1 EU`、执行时长倍率 `×1.5`、能耗线性、断汽回退 `1 tick`、每仓 `1,200 mB/t`——逐项确认沿用与否。

### 议题 6：并行与吞吐

- 最大并行（建议 `16`，大型机档位）；公式与“最近成功配方优先”沿用与否。

### 议题 7：内部库存与批处理原子性

- 沿用 C1a 口径与否（缓存仅待输出，`1 → 1` 输入输出预检最简）。

### 议题 8：运行控制与失效

- 沿用 C1a 口径与否。

### 议题 9：表现与信息

- GUI/Jade 沿用粉碎机骨架；`FORGE_HAMMER` 声效（类型自带蒸汽皮肤）与锻打粒子；两级物品提示与本地化。

### 议题 10：获取配方与建造成本

- 配方含蒸汽装配方块 ×1 作为核心（锻打夹持语义）与否；轻量板件方向（延续 C1a/C1b 裁定）；不含仓室；恒产 1；图案随结构定案后给建议稿。

### 议题 11：工作强度三档

- 三档完全相同（全家族口径）与否。
