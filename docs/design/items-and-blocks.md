# 物品与方块总体设计

本文档汇总 Greg Steam Expansion 需要自行注册的普通物品与非机器方块，并记录由本模组补充获取方式的 GTCEu 现有方块。当前阶段不讨论单方块机器、多方块控制器、仓、总线或其他机器部件；这些内容稍后在各自的独立规格中处理。

## 当前设计范围

本阶段纳入：

- 可独立存在的材料物品、加工零件、工具与消耗品；
- 普通结构方块、机械外壳、耐火或承压方块与装饰方块；
- GTCEu 已注册但缺少合理获取方式、需要由本模组补充配方的普通物品或方块；
- 上述内容的名称、资源 ID、材料构成、获取方式、方块属性、标签和用途边界。

本阶段暂不纳入：

- 单方块机器及其输入、输出、GUI、配方处理和运行数值；
- 多方块控制器、机器结构、并行、温度、能耗和安全机制；
- 蒸汽仓、排气仓、总线、能源仓及其他机器接口；
- 为尚未设计的单台机器预先确定专属零件数量或强行注册一次性占位内容；可供多种后续内容复用的标准化合成组件不受此限制。

## 设计目标

- 围绕 GTCEu 蒸汽时代补充有明确用途的物品与结构方块，不另建一套与 GTCEu 重复的基础材料体系。
- 每个新增内容都必须解决明确的玩法或配方组织需求。可被多个配方复用、具有稳定材料语义的标准化合成组件可以注册；只服务于单个配方的填充物、换皮物品或临时中间变量不应注册。
- 优先复用 GTCEu 已有板、管道、齿轮、粉和外壳，使新增内容能自然接入原有科技树与加工体系。
- 蒸汽阶段可获得的普通物品与方块必须具有无需电力的基础制作路线；进入电力时代后可以另有自动化路线，但不能以此取代前者。
- 资源 ID 不绑定可能调整的外观材料或平衡数值，避免后续调整破坏存档兼容性。

## 内容范围总览

当前阶段已经确认需要由本模组新注册的内容为 **3 个普通方块、1 个独立物品**。另有 **1 个 GTCEu 现有方块**正在设计补充配方；它不计入本模组的注册数量。机器与机器部件已移出当前统计。

| 当前类别 | 数量 | 说明 |
| --- | ---: | --- |
| 新增普通方块 | 3 | 蒸汽碾磨方块、蒸汽装配方块、蒸汽电路装配方块 |
| 新增独立物品 | 1 | 青铜构件 |
| 上游方块配方补全 | 1 | 为 GTCEu 工业蒸汽机械方块补充获取方式，不重复注册方块 |
| 暂缓的机器与机器部件 | 不统计 | 稍后另行讨论，不属于本阶段设计范围 |

## 正在设计：工业蒸汽机械方块

### 上游现状核验

| 字段 | 结论 |
| --- | --- |
| 状态 | 配方设计草案，尚未实现 |
| 类型 | GTCEu 已注册的普通机械外壳方块 |
| 中文名 | 工业蒸汽机械方块 |
| 英文名 | Industrial Steam Casing |
| 方块与物品 ID | `gtceu:industrial_steam_casing` |
| 上游注册字段 | `GCYMBlocks.CASING_INDUSTRIAL_STEAM` |
| 上游版本 | GTCEu 7.5.3 |
| 现有资源 | 已有方块状态、方块模型、物品模型、纹理、本地化、掉落表和挖掘标签 |
| 缺失内容 | GTCEu 7.5.3 没有注册任何产出该方块的手工或机器配方 |
| 本模组处理方式 | 只向现有 `gtceu` 方块添加配方，不以 `gregsteamexpansion` 命名空间重复注册方块或物品 |

### 玩法定位

- 作为工业级蒸汽建筑与设备可复用的标准外层机械方块，表现黄铜框架、金属蒙皮和能够承受连续蒸汽作业的封闭结构。
- 位于普通青铜蒸汽机械方块之后：普通蒸汽机械方块偏向砖砌隔热结构，工业蒸汽机械方块偏向完全由金属框架与板材构成的压力外壳。
- 科技阶段定为蒸汽时代中后期。玩家需要先取得黄铜并具备制作黄铜板和黄铜框架的能力，但不需要进入电力时代。
- 该方块本身不储存蒸汽、不传输流体、不提供容器能力，也没有 GUI；在本阶段只作为可放置、可回收的普通结构方块设计。
- 当前只建立材料、配方和普通方块定位，不指定任何机器必须使用它，也不讨论机器结构中的用量或替换规则。

### 选材依据

- 方块现有纹理以黄铜色金属为主，使用黄铜材料能够让配方和视觉保持一致。
- 黄铜由铜与锌组成，比直接使用青铜更能区分普通蒸汽机器与工业蒸汽机器，同时仍属于无需电力即可取得的材料。
- 旧版 Gregicality Multiblocks 中同一用途的 `Steam Casing` 采用 6 个黄铜板和 1 个黄铜框架；本模组以这一历史配方为基础恢复 GTCEu 7.5.3 遗漏的获取方式，而不重新发明另一套材料成本。
- 配方结构与 GTCEu 7.5.3 的实心钢机械方块、耐热机械方块等标准外壳一致，便于玩家从已有配方规律推断。

### 手工配方

工业蒸汽机械方块必须提供无需电力的有序工作台配方，作为蒸汽阶段的基础获取路线：

```text
P h P
P F P
P w P
```

| 符号 | 输入 |
| --- | --- |
| `P` ×6 | GTCEu 黄铜板（`plate / Brass`） |
| `F` ×1 | GTCEu 黄铜框架（`frameGt / Brass`） |
| `h` | GTCEu 锻造锤工具位，不消耗工具本体，只扣除耐久 |
| `w` | GTCEu 扳手工具位，不消耗工具本体，只扣除耐久 |

- 产出数量遵循 GTCEu 的 `recipes.casingsPerCraft` 配置，允许值为 `1–3`，默认产出 `2` 个。
- 配方资源 ID 暂定为 `gregsteamexpansion:shaped/industrial_steam_casing`。
- 配方上下不对称，锻造锤固定在上方、扳手固定在下方；左右镜像不会产生不同的材料排列或额外冲突。
- 该路线不得要求电路、马达、钢、机器外壳或任何电力时代产物。

### 组装机配方

进入低电压阶段后提供成本相同的组装机批量路线，减少大量制作结构方块时的手工操作：

| 项目 | 设计值 |
| --- | --- |
| 黄铜板输入 | 6 个 |
| 黄铜框架输入 | 1 个 |
| 编程电路 | 配置 `6`，不消耗 |
| 能耗 | `16 EU/t` |
| 持续时间 | `50 tick`（2.5 秒） |
| 总耗能 | `800 EU` |
| 产出 | 遵循 `recipes.casingsPerCraft`，默认 2 个工业蒸汽机械方块 |
| 配方资源 ID | `gregsteamexpansion:assembler/industrial_steam_casing` |

- 组装机路线只是低电压阶段的自动化便利，不得替代或锁定蒸汽阶段手工路线。
- 两条路线使用相同的材料成本和产出数量，组装机不提供额外材料增益。

### 注册与兼容边界

- 本模组不新增该方块的本地化、模型、纹理、掉落表、标签或创造模式页条目，全部继续使用 GTCEu 的现有注册内容。
- 配方输出必须直接引用 `gtceu:industrial_steam_casing`；不得复制其纹理并创建 `gregsteamexpansion:industrial_steam_casing`。
- 两份配方使用本模组命名空间，避免占用或覆盖 GTCEu 未来可能使用的配方 ID。
- 如果后续升级的 GTCEu 版本已经提供材料、产出和阶段定位等价的正式配方，应移除本模组的补充配方，避免配方查看器出现重复路线。
- 如果上游只增加了成本或阶段明显不同的配方，应先重新进行平衡审查，不自动保留两套获取方式。

### 本阶段暂不讨论

- 哪些机器使用该方块、每台机器使用多少以及它在结构中的具体位置。
- 它能否被仓、总线、控制器或其他机器接口替换。
- 它是否为某种机器提供效率、温度、压力、并行或其他运行加成。

上述问题全部留到机器设计阶段，不影响本阶段确定该方块的材料与获取方式。

## 已确认新增的普通物品与方块

### 青铜构件

#### 基本定义

| 字段 | 设计 |
| --- | --- |
| 状态 | 基础定位已确认，配方与表现为设计草案，尚未实现 |
| 类型 | 标准化合成组件、不可放置的普通物品 |
| 中文名 | 青铜构件 |
| 英文名 | Bronze Component |
| 资源 ID | `gregsteamexpansion:bronze_component` |
| 注册字段 | `BRONZE_COMPONENT` |
| 科技阶段 | 蒸汽时代 |
| 核心用途 | 作为后续多方块机器控制器及通用蒸汽结构部件的共享合成组件 |
| 最大堆叠 | 64 |
| 稀有度 | 普通 |
| 耐久 | 无 |

“青铜构件”表示已经完成框架加固与板材包覆的标准化青铜承力组件。它不是青铜材料的新形态，也不参与 GTCEu 的板、杆、框架等材料统一；其身份来自特定组合结构与后续配方用途。

#### 物品行为

- 物品不能放置，不提供右键使用行为、容器、流体能力、能量能力或可配置数据。
- 物品不具有耐久、附魔光效、燃料价值、容器返还物或特殊稀有度。
- 作为普通合成材料时会被正常消耗，不充当锻造模板或不可消耗催化剂。
- 堆叠中的所有青铜构件完全等价，不保存来源配方、制造者或其他数据组件。
- 首版不为其增加矿辞式通用标签；后续配方直接引用该物品，避免其他外观相近的青铜零件意外替代它。

#### 结构与材料语义

青铜构件由三类 GTCEu 青铜部件组成：

- 青铜框架形成中心承力骨架；
- 四块青铜板从四角包覆和固定框架；
- 两个青铜弹簧形成内部缓冲与预紧结构，用于吸收振动并补偿反复受热时的形变；
- 锻造锤负责铆合板材，扳手负责紧固框架连接，二者只扣除工具耐久。

配方不使用齿轮、转子或流体管道。青铜弹簧只表达构件内部的缓冲、预紧和热形变补偿，不代表青铜构件能够主动运动；需要旋转、泵送或流体输送功能的后续配方应在青铜构件之外另行加入对应零件。

#### 手工配方

青铜构件必须能够在纯蒸汽阶段通过有序工作台配方制作：

```text
P h P
S F S
P w P
```

| 符号 | 输入 |
| --- | --- |
| `P` ×4 | GTCEu 青铜板（`plate / Bronze`） |
| `S` ×2 | GTCEu 青铜弹簧（`spring / Bronze`） |
| `F` ×1 | GTCEu 青铜框架（`frameGt / Bronze`） |
| `h` | GTCEu 锻造锤工具位，不消耗工具本体，只扣除耐久 |
| `w` | GTCEu 扳手工具位，不消耗工具本体，只扣除耐久 |

- 每次固定产出 `1` 个青铜构件，不读取 GTCEu 的外壳产出数量配置。
- 配方资源 ID 暂定为 `gregsteamexpansion:shaped/bronze_component`。
- 配方左右对称；水平镜像不会产生新的材料排列。上下方向固定，以保持锻造锤和扳手工具位与其他 GTCEu 外壳类配方相近。
- 配方不使用电路、马达、泵、机器外壳、钢或其他电力时代产物。

#### 组装机配方

进入低电压阶段后提供材料成本更低的自动化路线。组装机能够以稳定压力完成板材固定和弹簧预紧，因此相较手工制作少用 1 块青铜板和 1 个青铜弹簧：

| 项目 | 设计值 |
| --- | --- |
| 青铜板输入 | 3 个 |
| 青铜弹簧输入 | 1 个 |
| 青铜框架输入 | 1 个 |
| 编程电路 | 配置 `6`，不消耗 |
| 能耗 | `16 EU/t` |
| 持续时间 | `50 tick`（2.5 秒） |
| 总耗能 | `800 EU` |
| 产出 | 1 个青铜构件 |
| 配方资源 ID | `gregsteamexpansion:assembler/bronze_component` |

- 组装机配方相较手工配方减少 1 块青铜板和 1 个青铜弹簧，但仍固定产出 1 个青铜构件。
- 材料节省是进入低电压阶段并建立自动化后的明确奖励，不向纯蒸汽阶段提供等价的低成本手工替代配方。
- 手工路线始终是青铜构件的基础获取方式，玩家不需要进入低电压阶段才能制作后续蒸汽时代内容。

#### 物品表现与提示

- 物品图标应表现一个紧凑的方形青铜框架：外轮廓使用较深的框架边缘，内部可见左右两组短弹簧线圈与分段加固板，中心保留少量暗色空隙以区别于完整方块。
- 图标使用 GTCEu 青铜材质的棕黄色范围，但轮廓必须与青铜板、青铜框架和普通机器外壳明显不同。
- 物品不需要动态纹理、自发光、动画或自定义模型；首版使用标准二维物品纹理。
- 默认提示只增加一行灰色用途说明：`用于组装大型蒸汽机械的标准化承力构件。`
- 对应英文提示：`A standardized load-bearing component for assembling large steam machinery.`
- 不设置按住 Shift 展开的详细提示；具体机器用途由以后各机器自己的配方和说明表达。

#### 用途边界

- 青铜构件应成为多种青铜或蒸汽时代大型内容共享的基础组件，不能只在单个配方中出现。
- 本阶段不确定任何具体机器消耗青铜构件的数量，也不以尚未设计的机器成本反推当前配方。
- 后续钢制或更高材料等级的组件是否存在，必须按实际内容需求单独设计；注册青铜构件不自动意味着需要建立全材料等级系列。
- 青铜构件不是方块，不能直接作为多方块结构中的一格，也不提供结构成型能力。

### 蒸汽碾磨方块

#### 基本定义

| 字段 | 设计 |
| --- | --- |
| 状态 | 基础定位与钻石研磨头需求已确认，其余内容为设计草案，尚未实现 |
| 类型 | 可放置的普通结构功能方块 |
| 中文名 | 蒸汽碾磨方块 |
| 英文名 | Steam Grinding Block |
| 资源 ID | `gregsteamexpansion:steam_grinding_block` |
| 注册字段 | `STEAM_GRINDING_BLOCK` |
| 科技阶段 | 蒸汽时代后期，取得钢与钻石之后 |
| 核心用途 | 作为后续多方块结构中承载碾磨机构的耐磨结构组件 |
| 方块物品 | 与方块同名、同 ID，最大堆叠 64 |

“蒸汽碾磨方块”表示已经把钻石研磨头、青铜小齿轮传动组和青铜板外壳组合为一体的封闭式碾磨模块。名称中的“蒸汽”表示其结构与材料面向蒸汽时代设备，不表示该方块能够脱离完整结构独立接收或消耗蒸汽。

#### 上游核心部件

- 配方必须消耗 1 个 GTCEu 钻石研磨头，物品 ID 为 `gtceu:diamond_grinding_head`，注册字段为 `GTItems.COMPONENT_GRINDER_DIAMOND`。
- GTCEu 7.5.3 的钻石研磨头由 4 个钢双层板、4 份钻石粉和 1 颗钻石制作，材料信息等价于 8 锭钢和 5 颗钻石。
- 钻石研磨头是方块成本与耐磨语义的核心，任何手工或机器制作路线都不得用普通钻石、钻石板、研钵、砂轮或其他研磨头代替。
- 钻石研磨头在合成时被永久装入方块并正常消耗；方块被破坏时只掉落自身，不返还研磨头。
- 当前不设计钨研磨头升级版，也不允许钨研磨头通过标签替代钻石研磨头。

#### 方块行为

- 方块是无方块实体、无内部库存、无流体槽、无能量槽的完整立方体。
- 方块不提供物品、流体、蒸汽、能量或红石能力，不具有 GUI，也不自行执行任何加工配方。
- 方块没有朝向、工作状态、含水状态或其他方块状态；所有方向使用同一结构语义，放置时无需校准方向。
- 方块不旋转、不产生粒子或声音，也不会伤害站立、接触或经过其表面的实体。
- 活塞可以按普通完整方块规则推动它；方块不受重力影响，不可燃，也不会被流体冲毁。
- 多方块机器以后可以将其识别为结构组件或进行客户端工作表现，但不得通过修改该方块的永久状态来实现运行动画。

#### 物理属性与采集

| 属性 | 设计值 |
| --- | --- |
| 硬度 | `5.0` |
| 爆炸抗性 | `6.0` |
| 声音类型 | 金属 |
| 光照 | 不发光 |
| 不透明度 | 完全不透明 |
| 碰撞箱 | 完整方块 |
| 挖掘工具 | 镐或 GTCEu 扳手 |
| 掉落 | 掉落自身，不需要精准采集 |

- 方块应加入与 GTCEu 机械外壳一致的镐或扳手可采集标签，并要求正确工具才能获得掉落。
- 爆炸掉落遵循普通方块规则，不保证在爆炸中返还，以保留钻石研磨头带来的建造风险。
- 方块不提供信标底座、附魔台增幅、音符盒特殊乐器或其他与结构用途无关的原版功能。

#### 手工配方

蒸汽碾磨方块必须提供无需电力的有序工作台配方：

```text
P G P
```

- 青铜构件位于中央，上下两个青铜齿轮表示同步精密夹持机构，四角青铜板形成工作面和防护结构。
- 配方材料上下对称；水平镜像只会交换剪线钳与扳手的位置，不改变材料成本或产出。
- 配方与蒸汽装配方块只在左侧工具位不同：前者使用剪线钳，后者使用锻造锤。玩家必须使用正确工具，不能由另一种方块配方代替。

#### 组装机配方

进入低电压阶段后提供材料成本更低的自动化路线：

| 项目 | 设计值 |
| --- | --- |
| 青铜板输入 | 2 个 |
| 青铜齿轮输入 | 2 个 |
| 青铜构件输入 | 1 个 |
| 编程电路 | 配置 `5`，不消耗 |
| 能耗 | `16 EU/t` |
| 持续时间 | `100 tick`（5 秒） |
| 总耗能 | `1,600 EU` |
| 产出 | 1 个蒸汽电路装配方块 |
| 配方资源 ID | `gregsteamexpansion:assembler/steam_circuit_assembly_block` |

- 组装机路线相较手工配方减少 2 块青铜板，但仍消耗完整的 1 个青铜构件和 2 个青铜齿轮。
- 编程电路必须使用配置 `5`；蒸汽装配方块继续使用配置 `4`，使材料输入相同的两份组装机配方具有唯一选择。
- 手工路线始终保持可用，玩家不需要进入低电压阶段才能制作蒸汽电路装配方块。

#### 模型与纹理方向

- 方块使用静态完整立方体模型，不使用方块实体渲染器、动画模型或自发光纹理。
- 外框延续蒸汽装配方块的青铜板、深色铆接边框和成对齿轮语言，使两者能被识别为同一结构系列。
- 中央工作面改为更细密的暗色定位孔、平行引线槽和四角小型夹具，不绘制已经完成的电路板或发光电子元件。
- 侧面可以加入剪线钳钳口形状的简化刻线或交叉导线槽，但不能直接复制剪线钳物品图标。
- 蒸汽装配方块使用宽大的通用夹具轮廓，蒸汽电路装配方块使用细密定位针与引线槽；两者必须能在 16×16 纹理下快速区分。
- 顶、底和侧面可以使用不同纹理，但侧面保持四向旋转对称，方块逻辑不增加朝向状态。
- 物品模型直接引用方块模型，不另做二维物品图标。

#### 名称与提示

- 默认提示增加一行灰色说明：`用于大型蒸汽机械结构的精密电路装配组件。`
- 对应英文提示：`A precision circuit assembly component for large steam machinery structures.`
- 不设置按住 Shift 展开的详细提示，不显示尚未确定的机器结构、电路等级、速度、并行或加工能力。
- 名称不使用“电路组装机”，避免暗示单独放置后可以执行电路组装机配方。

#### 用途边界

- 蒸汽电路装配方块是后续多方块结构的组成方块，不是控制器、机器接口、工作台或可独立工作的单方块机器。
- 本阶段不确定任何多方块结构需要多少蒸汽电路装配方块，也不定义数量对电路等级、速度、并行、良率或能耗的影响。
- 方块不得只作为蒸汽装配方块的装饰性换皮；后续至少一个多方块结构必须在成型规则中明确区分并要求该方块。
- 方块不具有电路槽、数据存储、静电、洁净度、焊接材料或元件损耗机制；相关机制留到机器设计阶段决定。
- 当前只设计一种蒸汽电路装配方块，不自动增加高压、钢制、洁净室或其他材料等级版本。

## 新条目准入条件

以后提出新物品或普通方块时，只有同时满足以下条件，才应加入“已确认”清单：

1. 有明确的玩家用途、所属科技阶段和与现有内容不同的职责。

3. 已确定中文名、英文名、资源 ID、获得方式以及是否可放置。
4. 已说明它作为独立物品、普通方块或跨多个配方复用的标准组件的实际用途；只为未来某一台机器服务的一次性占位组件不满足条件。
5. 已检查是否只是机器内部数值、纹理、GUI 图标、接口能力或配方中间变量；这些内容不应被注册成物品或方块。
6. 至少建立一份独立设计规格，或在既有规格中完成足够详细的行为定义。

## 当前结论

- 当前阶段为 **3 个新增普通方块、1 个新增独立物品**；机器与机器部件不参与统计。
- 青铜构件是首个确认新增的基础物品，作为后续多种大型蒸汽内容共享的合成组件；当前不指定任何具体机器的需求数量。
- 蒸汽碾磨方块是首个确认新增的普通结构功能方块，必须消耗 GTCEu 钻石研磨头，但自身没有独立加工能力。
- 蒸汽装配方块使用 1 个青铜构件和 2 个普通青铜齿轮，每次产出 1 个；组装机路线额外节省 2 块青铜板。
- 蒸汽电路装配方块与蒸汽装配方块成本相近，手工配方必须使用剪线钳；组装机以编程电路 `5` 与普通装配方块区分。
- 额外为 **1 个 GTCEu 现有普通方块**设计补充配方；工业蒸汽机械方块继续归 GTCEu 所有，不计为本模组新增注册内容。
- 工业蒸汽机械方块的草案采用历史一致的黄铜配方，并同时保留蒸汽阶段手工路线与低电压组装机路线。
- 工业蒸汽机械方块与未来机器之间的结构关系已经明确延后，不在当前阶段决定。
- 后续只将具有独立用途且无法合理复用 GTCEu 现有内容的物品或普通方块加入清单。
