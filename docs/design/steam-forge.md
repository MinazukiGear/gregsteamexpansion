### 配方执行细节（议题 3）

- 纯干式类型：`1` 物品入 / `1` 物品出、无流体、无电路——与 C1a 并列全家族最简输入输出面。

### 结构与外观（议题 4）

（用户 2026-09-07 确认；方块数量为推导核算）

- 固定单套结构，包围盒“长 `3`（前后）× 宽 `3`（左右）× 高 `5`”；**上三层（第 `3`–`5` 层）仅保留左右横向一行**（每层 `z=2` 中排的 `3` 格，居深度正中）；只允许四个水平朝向。
- 外壳全部使用青铜蒸汽机械方块（`gtceu:steam_machine_casing`，粉碎机家族口径）。
- **蒸汽装配方块 ×1**（`gregsteamexpansion:steam_assembly_block`）嵌于第 `2` 层中央（锻打工位核心，正对上方锻锤行中格）；其余全部为青铜蒸汽机械方块。
- 控制器位于正面底层正中（宽 `3` 有正中格）。

#### 逐层结构图

各层为 `3` 格宽 × `3` 行深，每行从上到下对应由正面向背面。符号：`B` 青铜蒸汽机械方块（仓室可替换位置）、`M` 蒸汽装配方块、`C` 控制器。

第 `1` 层（底层）：

```text
BCB  ← 正面（控制器位于正面底层正中）
BBB
BBB
```

第 `2` 层（锻台层）：

```text
BBB  ← 正面
BMB
BBB
```

第 `3`–`5` 层（锻锤行，仅左右横向中排一行）：

```text
...  ← 正面
BBB  ← 锻锤行
...  ← 背面
```

- 锻锤行已确认（2026-09-07 用户裁定）：左右横向一行（`z=2`，`x=1..3`），锻锤行中格正对锻台核心。
- 校验：体积 `9+9+9 = 27` 格 = 青铜蒸汽机械方块 `25` + 蒸汽装配方块 `1` + 控制器 `1`。
- 仓室：物品输入/输出总线 ≥`1`、蒸汽供给仓 ≥`1`；**不使用排气仓**（2026-09-07 全模组裁定：非大型蒸汽多方块不使用排气仓），本机无排气受阻判定；类型无流体槽，无流体仓。
- `25` 个青铜蒸汽机械方块候选位不设机械方块最低数量或仓室合计上限。
- 结构共用：沿用全模组口径——不设结构独占与间距排斥。

### 动力与蒸汽消耗（议题 5）

（用户 2026-09-07 确认）

- 仅接受 GTCEu 标准蒸汽，不消耗 EU；蒸汽换算率 `2 mB = 1 EU`。
- 执行时长为配方基准耗时乘固定倍率 `1.5×`：`max(1, ceil(基准耗时 × 1.5))` tick；单份总耗汽 = `配方 EU/t × 执行时长 × 2` mB（类型无默认 `EU/t` 与耗时，按配方自带数值计算）。
- 能耗口径沿用家族的**固定线性**：批次总耗汽与每刻需求按实际并行 `P` 线性放大。
- 断供蒸汽：进度回退至 `1 tick`，恢复后续跑原批次（本机不使用排气仓，无排气受阻判定）。
- 多供给仓不提高并行或效率；每仓 `1,200 mB/t` 上限沿用。

### 并行与吞吐（议题 6）

（用户 2026-09-07 确认）

- 最大并行固定 `8`。
- 实际并行 = `min(8, 可用输入份数, 最坏情况输出可容纳份数)`（输出预检含 `1` 物品位）；公式小于 `1` 不开工、不扣取；批次开始后锁定。
- 耗时不随并行倍增；批次总耗汽与每刻需求按 `P` 线性放大。
- 配方选择沿用“最近成功配方优先”。

### 内部库存与批处理原子性（议题 7）

（用户 2026-09-07 确认）

- 沿用 C1a 口径：控制器缓存仅待输出结果，无内部物品槽；全部库存由仓室直接承载（类型无流体）。
- 开工预检跨全部总线聚合执行（`1` 物品输入份数 + `1` 物品输出位）；通过后一次原子扣取输入。
- 产物提交：一次性写入物品输出总线（跨总线/槽拆分堆叠）；待输出保险沿用。

### 运行控制与失效（议题 8）

（用户 2026-09-07 确认）

- 标准 GTCEu 启停控制：软锤 + GUI 电源按钮；暂停期间不取汽、不推进，批次参数保留。
- 一般结构失效：进度回退 `1 tick`，修复后续跑原批次。
- 无特殊清空关键部位；控制器被拆除仅损失偏好配方 ID 与待输出结果（物品掉落）。
- 区块卸载持久化续跑，不补算离线进度；新注册机器无旧存档迁移问题。

### 表现与信息（议题 9）

（用户 2026-09-07 确认）

- GUI/Jade 整体沿用粉碎机已实现骨架：主状态、配方与进度、实际并行与上限（`x / 8`）、蒸汽合计存量与容量、每刻需求、待输出摘要；服务端权威同步。
- 进度条与声效沿用类型自带样式（锻压进度条自带蒸汽皮肤、`FORGE_HAMMER` 声）；配方实际推进时在锻锤行叠加锻打粒子。
- 控制器正面空闲/工作两态纹理走 `steamMultiblockModel` 的 `addTextureOverride` 模式。
- 两级物品提示（默认摘要 + Shift 完整说明）；文本优先复用既有资源，中英双语。

### 获取配方（议题 10）

（用户 2026-09-07 确认，含同日“改用活塞”修订与配方重合修正）

- 配方**含原版活塞 ×1 作为核心**（压缩推压/锻打语义；用户裁定以活塞替代蒸汽装配方块以降低造价）；不含任何仓室；纯蒸汽时代材料。
- 固定有序工作台配方，每次恒产 `1` 个控制器，三档相同；配方 ID `gregsteamexpansion:shaped/steam_forge`。图案已确认（2026-09-07 用户确认）：

```text
P G P
P X P
P P P
```

| 符号 | 输入 | 数量 |
| --- | --- | ---: |
| `X` | 原版活塞（`minecraft:piston`，锻压核心，居中） | `1` |
| `G` | 青铜小齿轮（`gearSmall / Bronze`，顶部中格锤驱动） | `1` |
| `P` | 青铜板（`plate / Bronze`） | `7` |

- **配方重合修正（2026-09-07）**：C1a 蒸汽压缩机的配方为“板 7 + 活塞居中 + 小齿轮底行”——本机若沿用同位摆法将与 C1a 完全重合（vanilla 工作台无法区分两份相同输入的配方）。故将小齿轮移至顶部中格以逐格区分；左右对称无需序列化器；九项材料恰好占满 `3×3`。
- **全模组最轻控制器**（与 C1a 并列）：折算约 1 小齿轮 + 1 活塞 + 11 板（活塞为原版低成本方块），符合“造价过于昂贵”的修订要求。

### 配方特点

- 锻压配方覆盖面广：材料成型（`MaterialRecipeHandler`）、矿石锻碎（`OreRecipeHandler` 的 `ORE_FORGING` 分类，`ore-crushing.md` 确认保留）、零件锻造（`PartsRecipeHandler`）、电路相关（`CircuitRecipes`）、原木/石头类处理（`VanillaStandardRecipes`、`StoneMachineRecipes`）与机器回收（`MachineRecipeLoader`）。
- 纯干式 `1 → 1` 类型，输入输出面为全类型最简。

### 上游执行机器

| 机器 | 形态 | 与本机的关系 |
| --- | --- | --- |
| 锻造锤（`FORGE_HAMMER`） | LV–UV 单方块电力机器 | 同类型越级对照 |
| 蒸汽锻造锤（`STEAM_HAMMER`） | 青铜低压 + 钢高压单方块蒸汽机器 | 规模化上位的直接对照物（保留不动） |
| 大型材料压制机（GCYM `large_material_press`） | 电力多方块（弯曲/压缩/锻造/成型四类型，可并行） | 电力对照物，分层共存 |
| 蒸汽锻压多方块 | **不存在** | 补空白立项（规模化上位） |

## 立项前提

1. **定位：规模化上位**（蒸汽锻造锤已存在，A4/C0/C1b/C1a 模式）：锻压工序的批量化与集中自动化。
2. **无电力多方块专属路线冲突**：GCYM 大型材料压制机按能源形态分层共存（B4 先例）。
3. **纯干式最简类型**：`1 → 1`、无流体、无电路——与 C1a 并列全家族最简输入输出面。
4. **越级模式沿用**：锻造锤属 LV 电力机器，越级使用、以蒸汽消耗为平衡代价。
