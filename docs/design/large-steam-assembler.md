### 分工边界（议题 2）

（用户 2026-09-07 确认）

- 仅执行 `gtceu:assembler` 配方类型；**不越界**装配线（`assembly_line`，独立类型的电力多方块）与电路组装机（`circuit_assembler`，独立类型，归属 B2 精密装配机候选）。
- 与电力组装机（LV–UV）沿用越级模式：越级使用、以蒸汽消耗为平衡代价、不限配方、电力路线原样保留。
- 手工合成路线保留：本机是组装工序的自动化加速，不是任何物品的唯一获取途径。

### 配方执行细节（议题 3）

（用户 2026-09-07 确认）

- 全配方开放：`gtceu:assembler` 类型全部配方及外部模组新增配方自动可用；本机不修改配方基准数值（类型无默认 `EU/t` 与耗时，换算按配方自带数值）。
- 编程电路作为普通配方输入，随物品输入总线进入并逐批原子扣取（S1 口径），不新增专用电路仓；装配配方大量依赖电路配置，该口径为本机供给核心。
- 流体输入槽（类型 `1` 个）按配方声明原样兼容；流体输入仓可为本模组蒸汽流体输入仓或 GTCEu 标准流体输入仓（B4 口径，可选或混用）。
- 类型无流体输出槽，本机不设任何流体输出接口。

#### 组装机槽位机制（议题 3 新增，本机独有）

（用户 2026-09-07 确认；用户原话：『在控制器UI中添加一槽位用于放置LV-EV组装机，该槽位为空时仅可运行ULV级配方，该槽位装入组装机时可运行该等级配方，且装入1-4个时增加并行至2/4/8/16』）

- 控制器 UI 增加“组装机槽位区”，可放置 `1–4` 台 GTCEu 电力组装机（`LV / MV / HV / EV` 四个电压等级的 `gtceu:assembler`）。
- **配方等级访问**：槽位为空时仅可运行 **ULV 级**配方；装入组装机后可运行该等级配方（本大纲解释口径：可运行 **不高于已装入最高等级** 的配方；**混装不同等级时以最高等级为准**——解释口径待复核）。
- **并行上限**：装入 `1 / 2 / 3 / 4` 台时并行上限提升至 `2 / 4 / 8 / 16`；槽位为空时并行上限为 `1`（议题 6 一并生效）。
- 组装机持久保存于槽位（跨区块卸载与世界重载保持），可随时取出；取出后立即按新状态重新判定。
- 组装机**不提供 EU**：机器仍仅消耗 GTCEu 标准蒸汽；耗汽按配方自身 `EU/t` 换算（议题 5），等级越高的配方天然消耗更多蒸汽——组装机槽位是“等级与并行的钥匙”，不是能源，越级平衡仍然落在蒸汽侧。
- 待复核解释口径：①混装等级时的配方访问（上述“以最高等级为准”）；②运行中批次期间取出组装机的处理（建议：已启动批次按启动时锁定的并行与等级跑完，下一批次按新状态判定——待复核）。

### 动力与蒸汽消耗（议题 5）

（用户 2026-09-07 确认，含同日能量规则重设）

- 仅接受 GTCEu 标准蒸汽，不消耗 EU；蒸汽换算率 `2 mB = 1 EU`。
- 单份配方基准：执行时长 = `max(1, ceil(配方基准耗时 × 1.5))` tick；每刻蒸汽需求 = `配方 EU/t × 2` mB/t（类型无默认 `EU/t` 与耗时，按配方自带数值计算）。
- **并行的能耗与耗时阶梯**（用户 2026-09-07 重设；均低于线性增长）：

| 实际并行 | 蒸汽每刻倍率 | 耗时倍率 |
| ---: | ---: | ---: |
| `1` | `×1.0`（保持不变） | `×1.0` |
| `2` | `×1.25` | `×1.5` |
| `4` | `×1.5` | `×2.0` |
| `8` | `×1.75` | `×2.5` |
| `16` | `×2.0` | `×3.0` |

- 结算口径：批次执行时长 = `ceil(配方基准耗时 × 1.5 × 耗时倍率)`；批次每刻需求 = `ceil(配方 EU/t × 2 × 蒸汽倍率)` mB/t；批次总耗汽 = 每刻需求 × 执行时长（整数结算）。
- 示例（EV `2,048 EU/t`、基准 `200 tick` 配方）：`1` 并行 `4,096 mB/t`、`300 tick`；`16` 并行 `8,192 mB/t`、`900 tick`。
- 断供蒸汽：进度回退至 `1 tick`（S1 口径），恢复后续跑原批次（按批次锁定的倍率续跑）；排气受阻按通用排气仓规则冻结进度，与缺气回退明确区分。
- 多供给仓不提高并行或效率；每仓 `1,200 mB/t` 机器侧上限沿用。

### 并行与吞吐（议题 6）

（用户 2026-09-07 确认，与议题 3 组装机槽位机制联动）

- 最大并行不由固定数值决定，而由已装入的组装机数量决定：空槽 `1`、`1` 台 `2`、`2` 台 `4`、`3` 台 `8`、`4` 台 `16`。
- 实际并行 = `min(当前并行上限, 可用输入份数, 最坏情况输出可容纳份数)`；可用输入份数按配方全部物品输入项（含编程电路）与流体输入（如有）共同计算；公式小于 `1` 不开工、不扣取。
- 批次开始时锁定实际并行、配方等级与组装机状态；批次运行期间槽位变化不影响已锁定批次（解释口径待复核，见议题 3）。
- 耗时与蒸汽消耗按议题 5 的并行阶梯结算（次线性增长）：吞吐随并行次线性提升（`16` 并行为单并行的 `5.33` 倍），**单位产物的蒸汽成本随并行降低**（`16` 并行单件能耗为单并行的 `37.5%`），代价是每刻蒸汽需求上升、需要更多供给仓。
- 配方选择沿用“最近成功配方优先”：尚未保存偏好时按输入槽编号从小到大扫描，多匹配按资源 ID 字典序；偏好配方持久化，缺输入重扫、输出不足等待不改选；**槽位为空或组装机等级不足时，偏好配方暂不可用则回退扫描可运行配方，不视为改选**。

### 内部库存与批处理原子性（议题 7）

（用户 2026-09-07 确认）

- 沿用 S1 口径：控制器缓存仅待输出结果，无内部物品槽与内部流体罐；全部库存由仓室直接承载。
- 开工预检跨全部总线与流体输入仓聚合执行（配方最多 `9` 个物品输入项——本模组迄今最宽输入面——与 `1` 个流体输入项，概率输出按最坏情况预留）；通过后一次原子扣取全部输入。
- 类型仅 `1` 个物品输出位；产物提交时一次性写入物品输出总线（跨总线/槽拆分堆叠）。
- 待输出保险沿用（异常时完整物品结果持久化于控制器，空间恢复后整体重试）。

### 运行控制与失效（议题 8）

（用户 2026-09-07 确认）

- 标准 GTCEu 启停控制：软锤 + GUI 电源按钮；暂停期间不取汽、不推进，批次参数保留。
- 一般结构失效：进度回退 `1 tick`，修复后续跑原批次。
- 无特殊清空关键部位；控制器被拆除仅损失偏好配方 ID、组装机槽位内容与待输出结果——**组装机槽位中的电力组装机以物品实体掉落返还**，不消失。
- 区块卸载持久化续跑（含组装机槽位内容），不补算离线进度；新注册机器无旧存档迁移问题。

### 配方特点（影响本机设计的客观事实）

- 装配配方散布全科技树（机器零件、框架、管道、组件、电路外围等），数量庞大。
- **编程电路配置（`circuitMeta`）在装配配方中大量使用**，是配方组成的一部分。
- 流体输入槽存在但使用面较窄（部分配方声明流体）。
- 上游**不存在蒸汽组装机**（蒸汽机器仅有锅炉 ×3、提取机、研磨机、压缩机、锻造锤、熔炉、合金炉、岩石破碎机），也没有任何多方块执行 `gtceu:assembler` 类型。

## 立项前提

1. **定位：补空白（同 S1/B4 模式）**。上游没有蒸汽组装机，本机是蒸汽阶段首次获得自动化组装能力的入口。
2. **越级模式沿用**：组装机属 LV 电力机器；沿用 S1 议题 2 确立的“越级使用、以蒸汽消耗为平衡代价、不限配方、电力路线原样保留”。
3. **孤儿消化**：蒸汽装配方块（`gregsteamexpansion:steam_assembly_block`，工作台/夹具/机械传动语义）由本机消化；电路装配方块留给 B2 精密装配机。
4. **设计重点**：`9` 个物品输入槽是本模组迄今最宽的输入面；组装机槽位机制使并行上限与配方等级成为机器的“可成长维度”——这是本模组第一台带成长性机制的机器。

## 验收清单（由用户执行）

**结构与成型**

- [ ] `9×9×9` 包围盒结构按逐层图成型（正面底层正中为控制器）：外壳 386 格（顶底面与棱 190 格工业区＝189 工业蒸汽机械方块 + 控制器；四面墙体 196 蒸汽机械方块）、装配工位 18（第 2、8 层各 9 个间隔网格）、内部空气 325。
- [ ] 仓室仅替换墙体蒸汽机械方块位置；顶底面与棱的工业方块不可替换。
- [ ] 排气仓缺省、多余或正面 `3` 格空气受阻时按既定规则处理；结构可共用。

**组装机槽位机制**

- [ ] 槽位为空：仅可运行 ULV 级配方，并行上限 `1`。
- [ ] 装入 `1 / 2 / 3 / 4` 台组装机：并行上限 `2 / 4 / 8 / 16`；可运行配方等级符合确认口径。
- [ ] 组装机跨重载保留于槽位；取出返还物品；运行中取出按锁定批次处理。
- [ ] 组装机不提供 EU：运行仍消耗蒸汽且按配方 `EU/t` 换算。

**配方与并行**

- [ ] `gtceu:assembler` 全配方及外部配方自动可用；编程电路随物品输入总线进入并逐批扣取。
- [ ] 执行时长与耗汽按并行阶梯结算（`1 / 2 / 4 / 8 / 16` 并行：蒸汽每刻 `×1 / 1.25 / 1.5 / 1.75 / 2`、耗时 `×1 / 1.5 / 2 / 2.5 / 3`）；实际并行符合 `min(上限, 输入份数, 输出容纳份数)`。
- [ ] 断汽回退 `1 tick` 后续跑；配方选择遵循“最近成功配方优先”且跨重载保持。

**库存与控制**

- [ ] 控制器缓存仅待输出；待输出跨重载保留并整体提交。
- [ ] 软锤与 GUI 电源按钮启停正确；结构失效回退 `1 tick`；控制器拆除时组装机以物品掉落返还。

**表现与获取**

- [ ] GUI/Jade 信息与粉碎机骨架一致（并行 `x / 上限`、当前可运行等级显示）；组装机槽位显示正确。
