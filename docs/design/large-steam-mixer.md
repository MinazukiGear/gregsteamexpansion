### 分工边界（议题 2）

（用户 2026-09-07 确认）

- 仅执行 `gtceu:mixer` 配方类型；与 GCYM 大型搅拌机（电力多方块，可并行）按能源形态分层共存，保持上游原样。
- 与合金炉分工：合金炉“锭+锭→合金锭”直合金路线保留不动，本机承接混合粉尘路线（混合粉再冶炼）与流体混合——类型零重叠。

### 配方执行细节（议题 3）

（用户 2026-09-07 确认）

### 结构与外观（议题 4）

#### 固定结构

- 固定单套结构，包围盒“宽 `7`（左右）× 深 `5`（前后）× 高 `5`”，正面为 `7×5` 的面；只允许四个水平朝向。
- 外壳两区划分（B1/B2 大型机同款）：
  - 底面、顶面与 `12` 条棱（各相邻外壳面的共用部分）：工业蒸汽机械方块（`gtceu:industrial_steam_casing`）；
  - 前后左右四面墙体的非共用部分：蒸汽机械方块（`gtceu:steam_machine_casing`），为仓室唯一可替换位置。
- 内部 `5×3×3` 共 `45` 格为结构内部空间。
- **蒸汽搅拌方块 ×7**（`gregsteamexpansion:steam_mixing_block`，等距十字摆位，2026-09-07 用户确认）：**中轴立柱 `3`**（第 `2`–`4` 层内部中心 `x=4, z=3`）+ **中层叶轮十字 `4`**（第 `3` 层四正方向 `x=3/5, z=3` 与 `x=4, z=2/4`，四臂均紧邻轴心）——搅拌轴 + 叶轮语义；不提供任何数值加成。
- 其余内部 `38` 格固定空气。
- 控制器位于正面底层水平正中（宽 `7` 有正中格，位于底面工业区）。

各层为 `7` 格宽 × `5` 行深，每行从上到下对应由正面向背面。符号：`I` 工业蒸汽机械方块（底面、顶面与棱，不可替换）、`B` 蒸汽机械方块（四面墙体，仓室唯一可替换位置）、`A` 空气、`M` 蒸汽搅拌方块、`C` 控制器。

### 动力与蒸汽消耗（议题 5）

（用户 2026-09-07 确认）

- 仅接受 GTCEu 标准蒸汽，不消耗 EU；蒸汽换算率 `2 mB = 1 EU`。
- 执行时长为配方基准耗时乘固定倍率 `1.5×`：`max(1, ceil(基准耗时 × 1.5))` tick；单份总耗汽 = `配方 EU/t × 执行时长 × 2` mB（类型无默认 `EU/t` 与耗时，按配方自带数值计算）。
- 能耗口径沿用 C0/C1 家族的**固定线性**：批次总耗汽与每刻需求按实际并行 `P` 线性放大。
- 断供蒸汽：进度回退至 `1 tick`，恢复后续跑原批次；大型机排气受阻按通用排气仓规则冻结进度，与缺气回退明确区分。
- 多供给仓不提高并行或效率；每仓 `1,200 mB/t` 上限沿用。

### 并行与吞吐（议题 6）

（用户 2026-09-07 确认）

- 最大并行固定 `16`（梯度：小型 8 → 本机 16 → 洗矿/研磨 64）。
- 实际并行 = `min(16, 可用输入份数, 最坏情况输出可容纳份数)`；可用输入份数按配方全部物品输入项与双流体输入项共同计算；公式小于 `1` 不开工、不扣取；批次开始后锁定。
- 耗时不随并行倍增；批次总耗汽与每刻需求按 `P` 线性放大。
- 配方选择沿用“最近成功配方优先”。

### 内部库存与批处理原子性（议题 7）

（用户 2026-09-07 确认）

- 沿用全模组口径：控制器缓存仅待输出结果，无内部物品槽与内部流体罐；全部库存由仓室直接承载。
- 开工预检跨全部仓室聚合执行：最多 `6` 个物品输入项、`2` 个流体输入项的份数，与最坏情况输出（`1` 物品位 + `1` 流体位）预留；通过后一次原子扣取全部输入（含双流体）。
- 产物提交：物品写入物品输出总线，流体写入流体输出仓（分别提交）；待输出保险沿用（异常时完整结果持久化于控制器，空间恢复后整体重试）。

### 运行控制与失效（议题 8）

（用户 2026-09-07 确认）

- 标准 GTCEu 启停控制：软锤 + GUI 电源按钮；暂停期间不取汽、不推进，批次参数保留。
- 一般结构失效：进度回退 `1 tick`，修复后续跑原批次。
- 无特殊清空关键部位；控制器被拆除仅损失偏好配方 ID 与待输出结果（物品掉落，流体丢失）。
- 区块卸载持久化续跑，不补算离线进度；新注册机器无旧存档迁移问题。

### 表现与信息（议题 9）

（用户 2026-09-07 确认）

- GUI/Jade 整体沿用粉碎机已实现骨架：主状态、配方与进度、实际并行与上限（`x / 16`）、蒸汽合计存量与容量、每刻需求、待输出摘要；服务端权威同步。
- 进度条与声效沿用类型自带样式（`MIXER` 声）；配方实际推进时在搅拌方块位置叠加搅拌旋涡粒子。
- 控制器正面空闲/工作两态纹理走 `steamMultiblockModel` 的 `addTextureOverride` 模式。
- 两级物品提示（默认摘要 + Shift 完整说明）；文本优先复用既有资源，中英双语。

### 获取配方（议题 10）

（用户 2026-09-07 确认，含同日“齿轮换转子”修订与配方重合修正）

- 配方**含蒸汽搅拌方块 ×1 作为核心**（S1 先例，搅拌方块多消费者合法）；不含任何仓室；纯蒸汽时代材料。
- 固定有序工作台配方，每次恒产 `1` 个控制器，三档相同；配方 ID `gregsteamexpansion:shaped/large_steam_mixer`。图案已确认（2026-09-07 用户确认）：

```text

P M P
C R C
```

| 符号 | 输入 | 数量 |
| --- | --- | ---: |
| `M` | 蒸汽搅拌方块（`gregsteamexpansion:steam_mixing_block`，混合核心，居中） | `1` |

- **配方重合修正（2026-09-07）**：用户裁定齿轮换转子后，直接替换将得到与 S1 洗矿厂控制器配方（`P R P / C S C / P R P`）完全相同的输入网格——vanilla 工作台无法区分两份相同输入的配方。故将四角改为青铜构件、左右改为青铜板以逐格区分，转子保持上下搅拌轴位；图案四向对称，无需序列化器；九项材料恰好占满 `3×3`。

### 配方特点

- 混合配方覆盖面广：混合粉尘（合金粉路线）、橡胶混炼、培养液、电池化学、高阶金属组与杂项处理（`MixerRecipes`、`MachineRecipeLoader`、`GrowthMediumRecipes`、`BatteryRecipes`、`NaquadahRecipes`、`PlatGroupMetalsRecipes`、`MiscRecipeLoader`、`VanillaStandardRecipes`、`GCYMRecipes` 等）。
- 流体输入最多 `2` 槽、流体输出 `1` 槽——立项机器中最宽的流体面。

### 上游执行机器

| 机器 | 形态 | 与本机的关系 |
| --- | --- | --- |
| 搅拌机（`MIXER`） | LV–UV 单方块电力机器 | 同类型越级对照 |
| 大型搅拌机（GCYM `large_mixer`） | 电力多方块（可并行） | 电力对照物，分层共存 |
| 蒸汽搅拌机 | **不存在** | 补空白立项 |

## 立项前提

1. **定位：补空白（同 S1/B4/B1 模式）**。上游没有蒸汽搅拌机，本机是蒸汽阶段首次获得自动化混合能力的入口。
2. **橡胶链闭环**：提取机（C1b）供生胶、本机混炼、装配双机消费——橡胶链在蒸汽时代内部完整。
3. **与合金炉分工**：蒸汽合金炉“锭直合金”路线保留不动，本机承接混合粉尘与流体混合，类型零重叠。
4. **流体面设计重点**：`2` 流体入 + `1` 流体出是立项机器中最宽的流体面，双向仓室口径均已由 B4/C0 先例覆盖。
