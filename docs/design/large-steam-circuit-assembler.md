### 分工边界（议题 2）

（用户 2026-09-07 确认）

- 仅执行 `gtceu:circuit_assembler` 配方类型；不越界组装机（`assembler` 类型，归 B1）与装配线（`assembly_line` 类型）。
- 与电力电路组装机（LV–UV，带污染减益标志）沿用越级模式：越级使用、以蒸汽消耗为平衡代价、不限配方、电力路线原样保留。
- 手工/电力路线保留：本机是电路量产的自动化加速，不是任何物品的唯一获取途径。
- 与 B1 分工：B1 跑通用装配、本机跑电路装配，类型零重叠（S1/B4 分工模式的复用）。

### 配方执行细节与电路组装机槽位机制（议题 3）

（用户 2026-09-07 确认：细节与 B1 大型蒸汽组装机保持一致）

- 全配方开放：`gtceu:circuit_assembler` 类型全部配方（含上游自动补焊液的配方）及外部模组新增配方自动可用；本机不修改配方基准数值。
- **编程电路/物品输入随物品输入总线进入并逐批原子扣取**（S1/B1 口径）。
- **流体输入仓必须安装**：每条电路装配配方都强制带流体输入（上游为缺省流体配方自动补浸焊液合金 `L/2 × 焊料倍率`）；流体输入仓可为本模组蒸汽流体输入仓或 GTCEu 标准流体输入仓（B4 口径，可选或混用）。
- **电路组装机槽位机制（原样镜像 B1）**：控制器 UI 设槽位区，可放置 `1–4` 台 GTCEu 电力电路组装机（`LV / MV / HV / EV`）：
  - 槽位为空时仅可运行 **ULV 级**配方，并行上限 `1`；
  - 装入 `1 / 2 / 3 / 4` 台时并行上限提升至 `2 / 4 / 8 / 16`，可运行不高于已装入最高等级的配方（混装以最高等级为准——沿用 B1 待复核口径）；
  - 槽内电路组装机持久保存（跨卸载/重载）、可取出，控制器被拆除时以物品实体掉落返还；
  - 槽内机器**不提供 EU**：机器仅消耗蒸汽，耗汽按配方 `EU/t` 换算，等级越高天然越吃汽。
- 运行中批次取出槽内机器的处理沿用 B1 待复核口径：已启动批次不受影响，下一批次生效。

### 动力与蒸汽消耗（议题 5）

（用户 2026-09-07 确认：与 B1 保持一致）

- 仅接受 GTCEu 标准蒸汽，不消耗 EU；蒸汽换算率 `2 mB = 1 EU`。
- **并行能耗/耗时沿用 B1 次线性阶梯**（低于线性增长）：

| 实际并行 | 蒸汽每刻倍率 | 耗时倍率 |
| ---: | ---: | ---: |
| `1` | `×1.0`（保持不变） | `×1.0` |
| `2` | `×1.25` | `×1.5` |
| `4` | `×1.5` | `×2.0` |
| `8` | `×1.75` | `×2.5` |
| `16` | `×2.0` | `×3.0` |

- 结算口径：批次执行时长 = `ceil(配方基准耗时 × 1.5 × 耗时倍率)`；批次每刻需求 = `ceil(配方 EU/t × 2 × 蒸汽倍率)` mB/t；批次总耗汽 = 每刻需求 × 执行时长（整数结算；类型无默认 `EU/t` 与耗时，按配方自带数值）。
- 断供蒸汽：进度回退至 `1 tick`，恢复后续跑原批次（按批次锁定倍率）；排气受阻冻结进度，与缺气回退明确区分。
- 多供给仓不提高并行或效率；每仓 `1,200 mB/t` 上限沿用。

### 并行与吞吐（议题 6）

（用户 2026-09-07 确认，与议题 3 槽位机制联动）

- 最大并行随电路组装机槽位动态：空槽 `1`、`1` 台 `2`、`2` 台 `4`、`3` 台 `8`、`4` 台 `16`。
- 实际并行 = `min(当前并行上限, 可用输入份数, 最坏情况输出可容纳份数)`；可用输入份数按配方全部物品输入项与强制流体输入共同计算；公式小于 `1` 不开工、不扣取。
- 批次开始时锁定实际并行、配方等级与槽位状态；运行中槽位变化不影响已锁定批次（沿用 B1 待复核口径）。
- 吞吐特性同 B1：次线性提升（`16` 并行为单并行的 `5.33` 倍）、单位产物蒸汽成本随并行降低。
- 配方选择沿用“最近成功配方优先”；槽位为空或等级不足时偏好配方不可用则回退扫描可运行配方。

### 内部库存与批处理原子性（议题 7）

（用户 2026-09-07 确认，与 B1 一致）

- 控制器缓存仅待输出结果，无内部物品槽与内部流体罐；全部库存由仓室直接承载。
- 开工预检跨全部总线与流体输入仓聚合执行（配方最多 `6` 个物品输入项 + `1` 个强制流体输入项，概率输出按最坏情况预留）；通过后一次原子扣取全部输入（含焊液）。
- 类型仅 `1` 个物品输出位；产物一次性写入物品输出总线（跨总线/槽拆分堆叠）。
- 待输出保险沿用（异常时完整物品结果持久化于控制器，空间恢复后整体重试）。

### 运行控制与失效（议题 8）

（用户 2026-09-07 确认，与 B1 一致）

- 标准 GTCEu 启停控制：软锤 + GUI 电源按钮；暂停期间不取汽、不推进，批次参数保留。
- 一般结构失效：进度回退 `1 tick`，修复后续跑原批次。
- 无特殊清空关键部位；控制器被拆除仅损失偏好配方 ID、电路组装机槽位内容与待输出结果——**槽内电路组装机以物品实体掉落返还**。
- 区块卸载持久化续跑（含槽位内容），不补算离线进度；新注册机器无旧存档迁移问题。

## 立项前提

1. **定位：补空白（同 S1/B4/B1 模式）**。上游没有蒸汽电路组装机，本机是蒸汽阶段首次获得电路量产能力的入口。
2. **越级模式沿用**：电路组装机属 LV 电力机器；候选清单原有“涉及电路前驱体、越级风险更高”的顾虑随用户立项决定消解——蒸汽时代自产电路正是本机的立项价值。
3. **孤儿消化**：蒸汽电路装配方块（`gregsteamexpansion:steam_circuit_assembly_block`）是四个结构方块孤儿中最后一个，由本机消化。
4. **与 B1 成对**：类型零重叠；槽位机制、能量阶梯、库存与控制口径全部与 B1 一致，实现可直接复用 B1 骨架。
5. **设计重点**：每条配方强制流体输入（焊液），流体输入仓为常态必需接口。
