# 大型机器专属外挂模块候选库

> 状态：候选目录，不代表批量立项或定案。更新时间：2026-09-20。

本文档集中保存当前大型机器与大型设施可采用的主体外附属结构，供后续选型、讨论和单项立项使用。候选可以与现有定案冲突，但冲突项只能作为替代路线参考；没有单独获得用户确认前，不得据此修改机器实现、配方、结构或数值。

## 使用规则

### 统一五面槽

- 主体正面保留控制器、GUI 与操作空间，不设置外挂槽；左、右、后、上、下各为一个逻辑槽位。
- 槽位随主体的四个水平朝向一起旋转；“上”和“下”保持世界竖直方向不变。
- 每个候选固定占用一个槽位，同一面只能安装一个模块，同种模块不能重复。不同面默认可以共存；表中注明互斥或替代时，以注明关系为准。
- 模块包围盒不得与其他主体或外挂共享。底部模块需要玩家预留地下空间，但不因此改变主体结构图案。
- 主体没有外挂时仍须独立成型和运行。模块结构不完整、归属冲突或范围未加载时不得提供收益；具体状态清除、保留和批次恢复规则在模块正式立项时确定。

### 控制与接口

- 每个模块只服务表中指定的单个机器族；名称或机制相似的模块也不得注册为跨机器通用模块。
- 模块不得拥有独立控制器、独立运行循环或独立 GUI。检测、所有权、库存、持久化、状态提示和结算均由主体控制器负责。
- 模块可以使用专用仓口或槽位，但它们只能代理主体控制器持有的能力；模块方块不能保存一份独立库存或自行处理配方。
- 所有模块效果必须在批次或周期开始时锁定，不能在处理中通过瞬时搭建、拆除获得双重收益。正式规格必须补齐结构卸载、破坏、存档重载和控制器拆除规则。

### 状态、优先级与难度

| 标记 | 含义 |
| --- | --- |
| `✅ 已实现` | 已有代码与权威机器规格；本目录只提供入口，不复制完整数值。 |
| `🟢 兼容` | 不推翻当前核心定案，可作为增量机制立项。 |
| `🟡 修订` | 技术上可实现，但必须先修改既有机制、数值或状态规则。 |
| `🔴 冲突` | 直接违反配方边界、能源定位、固定并行、固定耗时或产率守恒，只保留为替代路线。 |

优先级采用“高 / 中 / 低”：已实现项固定为高；直接冲突、纯表现或明显重复路线通常为低；需要新增资源、接口或复杂持久化的候选通常为中；其余具有独立玩法循环且不引入新科技层级的候选为高。难度表示相对实现成本，不是玩法强度。

### 候选卡字段

下表每一行都是一张紧凑候选卡：稳定 ID、名称、固定槽位、状态、推荐优先级、实现难度、结构与机制、额外资源或接口、共存关系，以及与当前定案的关系。数值、尺寸、方块数、倍率、概率和配方成本均留待单项立项，不在候选阶段预先定案。

候选卡未写专用资源或接口时表示不新增 I/O；未写新增状态时表示只读取主体已有状态；未写额外互斥时适用“同面互斥、异面默认共存”。这些省略规则只用于压缩目录篇幅，不允许实现阶段自行补出隐藏库存、免费副产或跨机器能力。

## 后续选型与立项流程

1. 先按机器、机制标签和空闲槽位筛选候选，再排除同面互斥项。
2. 优先讨论“已实现”和“兼容”项；选择“修订”或“冲突”项时，必须明确列出要废止或改写的原定案。
3. 单项立项文档至少补齐：精确结构与朝向、材料和获取方式、数值公式、专用接口、组合顺序、批次锁定、卸载与破坏、NBT 迁移、GUI/Jade、结构预览、自动搭建及自动化测试。
4. 新模块定案后，在本目录把状态改为“已定案”或“已实现”，并链接机器权威规格；完整数值仍只维护在机器规格中，避免双份真相。
5. 新增机器时先决定是否属于本目录范围，再分配机器专属 ID 前缀；不得复用本表已有模块 ID 或把相似模块抽象为通用机器部件。

## 明确不在本目录中的内容

- 普通蒸汽粉碎机、压缩机、提取机、锻压机、化学浸洗厂和普通蒸汽离心机。
- 独立运行的附属机器、拥有独立控制器的子多方块，以及可安装到任意机器的通用升级模块。
- 已确定的最终尺寸、方块清单、配方、倍率、概率和性能预算；这些只在单项正式立项时决定。
