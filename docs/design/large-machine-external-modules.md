# 大型机器专属外挂模块设计库

> 状态：可评审设计库，不代表批量立项。最后重设计：2026-09-21。

本文档统一记录大型机器与大型设施的专属外挂模块。它既保存已经实现的模块入口，也为尚未实现的模块提供可直接评审的玩法契约。只有“候选”条目的名称、结构和数值尚未定案；任何候选进入实现前，仍须在所属机器规格中完成单项立项。“已否决”保留稳定 ID 与否决理由，但不再作为后续实现入口，除非用户明确重新立项。

本轮保留 `15` 个机器族与五面槽模型。锅炉房为修正安装面新增 `BR-T-16`，并永久保留退役的 `BR-R-06`，因此现有稳定 ID 共 `169` 个。候选只使用 Minecraft、GTCEu 与 GSE 已有的方块、物品、流体和配方；本目录不引入新的注册内容或配方。

## 统一模块契约

### 五面槽与几何

- 主体正面保留控制器、GUI 和操作空间，不设置外挂槽；左、右、后、上、下各为一个逻辑槽位。
- 槽位随主体的四个水平朝向旋转；上、下始终保持世界竖直方向。稳定 ID 中的 `L / R / B / T / D` 分别对应左、右、后、上、下，后续不得改变含义。
- 同一面只能安装一个模块，同种模块不得重复。异面模块默认可以共存；存在资源竞争、效果重复或状态顺序冲突时，候选卡必须额外注明。
- 模块完整包围盒不能与其他主体或模块共享。上、下模块需要玩家预留空间，但不并入主体成型图案。
- 主体始终可以不带外挂独立成型和运行；模块不是主体合法性的组成部分。

### 所有权、资源与状态

- 模块只服务所属机器族，不注册为跨机器通用升级。模块没有独立控制器、独立运行循环或独立 GUI。
- 结构验证、归属、资源能力、运行状态、NBT、信息展示和结算全部由主体控制器持有。模块方块不得保存隐藏库存或第二份流体。
- 模块只能使用主体已经能够访问的物品、流体和能力。需要水、空气、氧气、润滑剂、树脂、酸或其他既有资源时，必须通过主体托管接口显式预检和扣取。
- 开工型效果在批次或周期开始时锁定；逐 tick 效果只在模块持续有效且资源实际扣取时生效；完成型效果必须纳入最坏情况输出预检。不得通过临时搭建、拆除或区块卸载重复获益。
- 已加载范围内发生结构破坏、错档或归属冲突时，模块立即失效。候选若持有储量、熟练度或压力等状态，必须在卡片中说明清除或保留策略；正常服务器重启应先等待结构重新校验，不能把尚未加载误判为损坏。
- 性能模块可以提议修订耗时、耗汽、并行或单位产率，但必须明确代价和被修改的原定案。配方领域、电压门、蒸汽时代定位以及生产、储存、发电之间的职责边界仍是硬约束；越界方案只能标为“替代路线”。

### 状态字段

| 字段 | 取值 | 含义 |
| --- | --- | --- |
| 实现阶段 | `已实现` / `候选` / `已否决` | 已实现已有代码与权威规格；候选仍可逐项评审；已否决保留稳定 ID 和决定理由但不进入实现。此状态模型适用于本文档所有机器族。 |
| 定案影响 | `兼容` / `需修订` / `替代路线` | 是否保持当前机器定案，或需要修改固定经济，或必须替换机器身份边界。 |
| 优先级 | `高` / `中` / `低` | 综合玩法价值、辨识度、依赖和近期实施收益。 |
| 难度 | `低` / `中` / `高` / `已实现` | 预计结构、状态机、持久化、GUI 与测试成本。 |

“兼容”只表示不修改当前核心经济，不等于已经批准；“需修订”必须在卡片末尾写明被修改的规则；“替代路线”不得与当前定案同时生效。已实现条目的完整结构、数值和失效规则以所属机器规格为唯一真相。

### 候选卡读法

每行是一张完整的评审卡：稳定 ID 与安装面、实现阶段、定案影响、优先级和难度、模块收益与显式代价，以及结算时机、组合关系和需要改写的旧规则。未注明新增输入即表示不增加生产消耗；未注明状态即表示模块只读取主体权威状态。

## 选型与立项流程

1. 先从所属机器章节选择候选，再检查安装面、异面组合和主体周围空间；稳定 ID 只标识候选，不等于注册 ID。
2. 优先评审“兼容”候选；选择“需修订”时，必须在所属机器规格中明确废止或改写候选卡列出的旧规则；选择“替代路线”时，必须先重定机器身份与分工。
3. 单项立项至少补齐：精确结构与朝向、材料清单、数值公式、资源接口、效果顺序、批次锁定、输出预检、卸载与破坏、NBT 迁移、GUI/Jade、结构预览、终极终端自动搭建和自动化测试。
4. 模块定案或实现后，只在本目录更新阶段、影响和权威链接；完整数值继续维护在所属机器规格中，避免双份真相。
5. 新增模块必须使用新的稳定 ID，不得复用本表 ID，也不得因机制相似把机器专属模块抽象为任意机器通用升级。

## 明确不在本目录中的内容

- 普通蒸汽粉碎机、压缩机、提取机、锻压机、化学浸洗厂和普通蒸汽离心机。
- 拥有独立控制器或独立运行循环的附属机器，以及可安装到任意机器的通用升级物品。
- 新注册的物品、流体、方块或配方；若未来确有需要，必须先在独立内容规格中立项，再回到模块规格引用。
- 候选的最终尺寸、方块数、倍率、概率和性能预算；这些只在单项立项时确定。
