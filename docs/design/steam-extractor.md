### 分工边界（议题 2）

（用户 2026-09-07 确认）

- 仅执行 `gtceu:extractor` 配方类型；与 GCYM 大型提取机（电力多方块，可并行）按能源形态分层共存，保持上游原样。
- 与蒸汽提取机单方块（青铜低压 + 钢高压蒸汽机器）：规模化上位关系（A4/C0 模式），单方块保留不动。
- 越级模式沿用：提取机属 LV 电力机器，越级使用、以蒸汽消耗为平衡代价、电力路线原样保留。

### 配方执行细节（议题 3）

（用户 2026-09-07 确认）

- 执行 `gtceu:extractor` 类型全部配方（外部模组新增配方同规则），基准数值不修改（类型默认 `400 tick`、`2 EU/t`，配方可覆盖）。
- **LV 电压门：仅可执行电压等级 ≤ LV 的配方**（含 ULV；同 C0 离心机与上游蒸汽单方块行为），MV 及以上（含外部模组配方）被拒绝。
- 流体输出（类型 `1` 个流体输出槽）：产物经流体输出仓导出——可为 **GTCEu 标准输出仓或本模组蒸汽流体输出仓**，可选或混用（C0 口径）。
- 类型无流体输入槽、无编程电路要求，输入面为单物品（配方自带耗时与 `EU/t`，按配方自带数值计算）。

### 结构与外观（议题 4）

（用户 2026-09-07 确认，方块数量为推导核算）

- 固定单套结构，包围盒 `3×3×3`；只允许四个水平朝向。
- 外壳 `26` 格全部使用青铜蒸汽机械方块（`gtceu:steam_machine_casing`），其中正面底层正中 `1` 格为控制器；**内部唯一 `1` 格为青铜管道方块**（`gtceu:bronze_pipe_casing`，流体提取语义核心），无空气腔。

第 `1` 层（底层）：

```text
BCB  ← 正面（控制器位于正面底层正中）
BBB
BBB
```

第 `2` 层（中层）：

```text
BBB  ← 正面
BPB
BBB
```

第 `3` 层（顶层）：

```text
BBB
BBB
BBB
```

符号：`B` 青铜蒸汽机械方块（仓室可替换位置）、`P` 青铜管道方块、`C` 控制器。

- 校验：体积 `27` 格 = 外壳 `26`（`25` 青铜蒸汽机械方块 + 控制器）+ 青铜管道方块 `1`。
- 仓室：物品输入/输出总线 ≥`1`、蒸汽供给仓 ≥`1`、流体输出仓 ≥`1`（GTCEu 标准输出仓或本模组蒸汽流体输出仓，可选或混用）；类型无流体输入槽；**不使用排气仓**（2026-09-07 全模组裁定：非大型蒸汽多方块不使用排气仓），本机无排气受阻判定。
- `25` 个青铜蒸汽机械方块候选位不设机械方块最低数量或仓室合计上限。
- 结构共用：沿用全模组口径——不设结构独占与间距排斥。

### 动力与蒸汽消耗（议题 5）

（用户 2026-09-07 确认）

- 仅接受 GTCEu 标准蒸汽，不消耗 EU；蒸汽换算率 `2 mB = 1 EU`。
- 执行时长为配方基准耗时乘固定倍率 `1.5×`：`max(1, ceil(基准耗时 × 1.5))` tick；单份总耗汽 = `配方 EU/t × 执行时长 × 2` mB（默认基准 `400 tick`、`2 EU/t` 即 `600 tick`、`2,400 mB`）。
- 能耗口径沿用 C0 的**固定线性**：批次总耗汽与每刻需求按实际并行 `P` 线性放大。
- 断供蒸汽：进度回退至 `1 tick`，恢复后续跑原批次（本机不使用排气仓，无排气受阻判定）。
- 多供给仓不提高并行或效率；每仓 `1,200 mB/t` 上限沿用。

### 并行与吞吐（议题 6）

（用户 2026-09-07 确认）

- 最大并行固定 `8`（对照 C0 小型机/B4）。
- 实际并行 = `min(8, 可用输入份数, 最坏情况输出可容纳份数)`（输出预检含 `1` 物品位 + `1` 流体位）；公式小于 `1` 不开工、不扣取；批次开始后锁定。
- 耗时不随并行倍增；批次总耗汽与每刻需求按 `P` 线性放大（满并行 `8` 默认基准每刻 `32 mB/t`，单供给仓即可）。
- 配方选择沿用“最近成功配方优先”。

### 内部库存与批处理原子性（议题 7）

（用户 2026-09-07 确认）

- 沿用全模组口径：控制器缓存仅待输出结果，无内部物品槽与内部流体罐；全部库存由仓室直接承载。
- 开工预检跨全部仓室聚合执行（`1` 物品输入份数 + 最坏情况输出：`1` 物品位 + `1` 流体位）；通过后一次原子扣取输入。
- 产物提交：物品写入物品输出总线，流体写入流体输出仓（分别提交）；待输出保险沿用（异常时完整结果持久化于控制器，空间恢复后整体重试）。

### 运行控制与失效（议题 8）

（用户 2026-09-07 确认）

- 标准 GTCEu 启停控制：软锤 + GUI 电源按钮；暂停期间不取汽、不推进，批次参数保留。
- 一般结构失效：进度回退 `1 tick`，修复后续跑原批次。
- 无特殊清空关键部位；控制器被拆除仅损失偏好配方 ID 与待输出结果（物品掉落，流体丢失）。
- 区块卸载持久化续跑，不补算离线进度；新注册机器无旧存档迁移问题。

### 表现与信息（议题 9）

（用户 2026-09-07 确认）

- GUI/Jade 整体沿用粉碎机已实现骨架：主状态、配方与进度、实际并行与上限（`x / 8`）、蒸汽合计存量与容量、每刻需求、待输出摘要；服务端权威同步。
- 进度条与声效沿用类型自带样式（提取进度条与提取声效）；配方实际推进时在管道方块位置叠加提取粒子。
- 控制器正面空闲/工作两态纹理走 `steamMultiblockModel` 的 `addTextureOverride` 模式。
- 两级物品提示（默认摘要 + Shift 完整说明）；文本优先复用既有资源，中英双语。

### 获取配方（议题 10）

（用户 2026-09-07 确认，含同日“齿轮改小齿轮”修订）

- 配方**含青铜管道方块 ×1 作为核心**（流体语义先例：C0 大型机、焦炉仓青铜流体管道）；不含任何仓室；纯蒸汽时代材料。
- 固定有序工作台配方，每次恒产 `1` 个控制器，三档相同；配方 ID `gregsteamexpansion:shaped/steam_extractor`。图案已确认（2026-09-07 用户确认）：

```text
P P P
P T P
P G P
```

| 符号 | 输入 | 数量 |
| --- | --- | ---: |
| `T` | 青铜管道方块（`gtceu:bronze_pipe_casing`，流体提取核心，居中） | `1` |
| `G` | 青铜小齿轮（`gearSmall / Bronze`，底部传动；2026-09-07 用户修订，由普通青铜齿轮改为小齿轮） | `1` |
| `P` | 青铜板（`plate / Bronze`） | `7` |

- 图案沿用家族骨架（核心居中 + 底部传动 + 板包覆），与小型离心机配方同形、以中心方块区分（管道方块 vs 搅拌方块）；左右对称无需序列化器；九项材料恰好占满 `3×3`。
- **全模组最便宜的控制器**：折算约 1 小齿轮 + 1 管道方块 + 11 板（管道方块自身配方为 2 板 + 2 青铜管），符合橡胶链配套从属机的定位。

### 工作强度三档（议题 11）

（用户 2026-09-07 确认）

- 三档机器数值完全相同：并行、耗时、耗汽、产率、结构、接口、GUI/Jade 均不分档。
- 工作强度只通过结构方块合成成本自然生效；控制器配方三档恒产 `1`；档位切换对已成型机器无实际影响。

### 配方特点

- 提取配方散布广泛：橡胶与树脂加工（橡胶链核心）、回收拆解、电池拆包、分离化学、杂项处理（`RecyclingRecipes`、`SeparationRecipes`、`MiscRecipeLoader`、`VanillaStandardRecipes`、`MachineRecipeLoader`、`BatteryRecipes` 等）。
- 类型带 `1` 个流体输出槽。

### 上游执行机器

| 机器 | 形态 | 与本机的关系 |
| --- | --- | --- |
| 提取机（`EXTRACTOR`） | LV–UV 单方块电力机器 | 同类型越级对照 |
| 蒸汽提取机（`STEAM_EXTRACTOR`） | 青铜低压 + 钢高压单方块蒸汽机器 | 规模化上位的直接对照物（保留不动） |
| 大型提取机（GCYM `large_extractor`） | 电力多方块（可并行） | 电力对照物，分层共存 |

## 立项前提

1. **定位：规模化上位**（蒸汽提取机已存在，A4/C0 模式）。
2. **橡胶链价值**：B1/B2 的结构与控制器配方消耗大量橡胶片，本机是蒸汽时代橡胶的规模化来源。
3. **流体输出仓**：类型自带 `1` 流体输出槽，延续 C0 口径（蒸汽流体输出仓与 GTCEu 标准输出仓均可）。
4. **与 GCYM 大型提取机分层共存**：电力多方块保持上游原样。
