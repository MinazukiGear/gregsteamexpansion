# 终极终端

> 状态：2026-09-18 已实现首版；依赖 AE2 与 GTM Things 同时存在。本文记录本轮已定案并落地的行为，客户端实际观感与大型整合环境仍待游戏内验收。

## 定位与启用条件

终极终端是 GTM Things 高级终端的结构工程上位物，不替代后者。模组本体不把 AE2 或 GTM Things 设为硬前置：缺少任意一个依赖时 GSE 继续加载，物品不加入创造标签，条件配方不加载，已有物品只显示依赖缺失并拒绝使用。

终端支持 GTCEu 的 `IMultiController`，因此也支持复用同一图案系统的 GSE 多方块。玩家手持终端右击已放置且定向完成的控制器加入工程，Shift 右击移除；同一玩家最多保存 `16` 个同维度目标。对空气使用终端打开工程界面。

## 工程参数与模式

- `构建`与`修复`从控制器的实时 `BlockPattern` 解析缺失位置，并保留已经满足候选的现有方块；若目标格被不兼容且不可替换的方块占用，预检失败而不扣材料。
- `升级`除补齐缺失位置外，还会把图案内已有线圈换成所选线圈档位。被换下的线圈进入返还事务；未知占位方块、控制器、仓室和其他含方块实体的部件绝不自动替换。
- `拆除`只处理该终端成功放置并记录的普通结构方块，不拆控制器，不拆含方块实体的仓室或机器，不触碰玩家原先搭建的方块。
- 可变结构允许选择重复层数 `0–64`；`0` 表示使用图案最小值，实际值始终夹在图案声明的最小值与最大值之间。
- 线圈档位可选 `0–16`；`0` 使用图案的默认候选，其他值在候选线圈中选择最接近的档位。
- 仓室开关关闭时不主动把机器方块候选作为自动放置材料。所有结构仍必须通过 GTCEu 图案的最小数量约束，无法生成合法方案时任务失败。

## 材料、事务与队列

启动任务前先对全部目标生成确定性方案并汇总材料。系统完整模拟可用数量，确认足够后才从玩家物品栏提取；AE 开关开启时，余量从玩家物品栏内已绑定且可访问的 AE2 无线终端所连接网络提取。所有材料进入随世界保存的托管清单，避免进行中退出或服务器重启造成丢失或重复。

任务默认使用全服 `32` 方块/刻预算，可在 `gregsteamexpansion-terminal.toml` 的 `ultimateTerminalBlocksPerTick` 调整为 `1–256`。玩家离线、离开目标维度或目标区块没有自然加载时任务进入暂停，不强加载区块；条件恢复后继续。进行中与暂停中的任务都锁定目标清单，不能由新任务覆盖。

每个目标完成后必须再次通过控制器的真实图案校验。放置失败或最终校验失败时，只回滚本次为该目标新放置且不含方块实体的方块，并退还托管余料。退还和拆除所得优先进入玩家物品栏，其次写回 AE 网络；仍无法容纳的物品进入持久待领取清单，可在界面再次领取。

## 全息规划与部件配置

终端界面分为目标、预览、材料和部件四页。目标页选择当前控制器；预览页控制建造模式、重复层、线圈档位、仓室开关、机器类型模板或当前目标覆盖，以及全息显示方式；材料页可在当前目标与整个批次之间切换，分别显示需求、玩家背包、AE 网络和缺口；部件页从当前 `BlockPattern` 动态列出可互换位置的全部合法方块候选，并为每种候选设置目标数量。

关闭界面后，只要玩家任一只手继续持有终端，当前目标的世界内全息仍会显示。默认“仅差异”模式隐藏已满足方块；也可以切换完整结构或单层模式。预期方块使用半透明真实方块模型，状态轮廓为：缺失白色、冲突红色、升级黄色、拆除蓝色、区块未加载灰色。终端不强加载区块，未加载位置只作状态提示且禁止启动任务。

规划完全由服务端生成并校验。全量快照最多包含 `8,192` 个结构格、`256` 种候选和 `256` 种材料，超过部分被截断；客户端的部件加减请求只携带注册名和增减方向，服务端按实时图案重新计算合法上限。持有终端时每 `10 tick` 检查一次：目标、坐标或预期方块变化时发送新全量快照，仅状态与材料数量变化时发送增量更新。配置按控制器方块注册名保存为机器类型模板，也可为单个目标建立独立覆盖；旧版工程参数在读取时迁移到默认配置。

## 配方与美术

配方严格沿用 GTM Things 高级终端的 `SGS / PBP / PWP` 布局，只做用户指定的两项替换：中心书本 `B` 改为 `gtmthings:advanced_terminal`，所有钢零件改为 GTCEu 琥珀金零件。最终布局为：

```text
琥珀金螺丝 / 玻璃板 / 琥珀金螺丝
琥珀金板   / 高级终端 / 琥珀金板
琥珀金板   / 锡单导线 / 琥珀金板
```

贴图逐像素派生自 GTM Things 1.6.0 的高级终端：尺寸、轮廓、透明度、明暗、动画帧数和 `6 tick` 帧时完全保留，仅把有色像素的色相换为琥珀金金色。来源与 LGPL-3.0 例外记录在 `CREDITS.txt` 和 `LICENSE-ASSETS.txt`，生成过程由 `tools/gen_ultimate_terminal_texture.py` 固定。

## 验收边界

- 自动门禁：Java 编译、条件配方数据生成、程序化贴图逐像素新鲜度、双语键集合、精确九宫格配方，以及配置 NBT 往返和蓝图缺失/满足/冲突分类 GameTest。
- 待游戏内核对：四页界面、三种全息显示、模板/目标覆盖、候选计数、四种任务模式、AE 网络提取/退还、离线与跨重启续作、碰撞回滚、待领取物，以及大型结构的默认 `32` 方块/刻节流表现。
- 本轮不提供跨维度工程、AE 自动合成、团队共享、强加载区块、配置导入导出、未知占位方块替换，也不拆除终端没有亲自记录的结构。
