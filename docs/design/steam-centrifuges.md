### 类型范围与分工边界（议题 2）

（用户 2026-09-07 确认）

- **仅执行 `gtceu:centrifuge`（通用离心分离）类型**；`thermal_centrifuge`（热离心）类型不执行——矿石的“粉碎矿 → 离心粉碎矿”路线继续归上游热离心机，本机不接管。
- 与 GCYM 大型离心机（`large_centrifuge`，电力多方块，执行同一类型）按能源形态分层共存，保持上游原样。
- 与既有机器分工：本机是通用分离/流体处理的规模化设备；`centrifuge` 类型配方中的“纯净矿粉 → 粉尘”等分离路线归本机（A4 执行的 `macerator` 不含此配方）。
- 越级模式沿用：离心机属 LV 电力机器，越级使用、以蒸汽消耗为平衡代价、电力路线原样保留。

### 配方执行细节（议题 3）

（用户 2026-09-07 确认）

- 执行 `gtceu:centrifuge` 类型全部配方（外部模组新增配方同规则），基准数值不修改（类型默认 `EU/t = 5`、无默认耗时，按配方自带数值计算）。
- **电压门：仅可执行电压等级 ≤ LV 的配方**（含 ULV；同上游蒸汽单方块机器的等级限制行为）——MV 及以上的离心配方在本机不可运行；外部模组配方同受此门约束。
- 流体输出（类型最多 `6` 个流体输出槽）：产物经流体输出仓导出——可为 **GTCEu 标准输出仓或本模组蒸汽流体输出仓**，可选或混用（用户 2026-09-07 补充确认，B4 口径）；流体输入（类型最多 `1` 槽）按配方声明原样兼容，输入仓选型沿用 B4 口径（GTCEu 标准流体输入仓或本模组蒸汽流体输入仓均可）。
- 编程电路随物品输入总线进入（如配方要求），逐批按配方语义处理。

- 固定单套结构：外接 `7×7×9` 的立式分离塔，直径 `7` 圆截面（半径按“中心偏移 `d² ≤ 12.25`”判定，同 A4 球形圆片口径）拉高为 `9` 层；只允许四个水平朝向。
- 第 `1`、`9` 层为 `37` 格全填充圆盘冠；第 `2`–`8` 层为侧环（`16` 格）+ 内部区。

### 动力与蒸汽消耗（议题 5）

（用户 2026-09-07 确认）

- 仅接受 GTCEu 标准蒸汽，不消耗 EU；蒸汽换算率 `2 mB = 1 EU`。
- 执行时长为配方基准耗时乘固定倍率 `1.5×`：`max(1, ceil(基准耗时 × 1.5))` tick（`centrifuge` 无默认耗时的配方按自带数值计算）；单份总耗汽 = `配方 EU/t × 执行时长 × 2` mB。
- 能耗口径沿用粉碎机家族的**固定线性**：批次总耗汽与每刻需求按实际并行 `P` 线性放大（不用 B1/B2 次线性阶梯）。
- 断供蒸汽：进度回退至 `1 tick`，恢复后续跑原批次；大型机的排气受阻按通用排气仓规则冻结进度（小型机不使用排气仓，无此判定），与缺气回退明确区分。
- 多供给仓不提高并行或效率；每仓 `1,200 mB/t` 机器侧上限沿用。

### 并行与吞吐（议题 6）

（用户 2026-09-07 确认）

- 蒸汽离心机最大并行固定 `8`；大型蒸汽离心机最大并行固定 `64`（粉碎机家族先例）。
- 实际并行 = `min(各自上限, 可用输入份数, 最坏情况输出可容纳份数)`；输出预检含最多 `6` 个物品输出位与 `6` 个流体输出位的全命中预留；公式小于 `1` 不开工、不扣取；批次开始后锁定。
- 耗时不随并行倍增；批次总耗汽与每刻需求按 `P` 线性放大。
- 配方选择沿用“最近成功配方优先”（首扫按输入槽编号，多匹配按资源 ID 字典序；偏好配方持久化，缺输入重扫、输出不足等待不改选）。

### 内部库存与批处理原子性（议题 7）

（用户 2026-09-07 确认）

- 沿用 S1/B1 口径：控制器缓存仅待输出结果，无内部物品槽与内部流体罐；全部库存由仓室直接承载。
- 开工预检跨全部仓室聚合执行：物品输入、流体输入份数与最坏情况输出（`6` 物品位 + `6` 流体位全命中预留）一次预检；通过后一次原子扣取全部输入。
- 产物提交：物品写入物品输出总线，流体写入流体输出仓（分别提交）；待输出保险沿用（异常时完整物品结果持久化于控制器，流体结果与输出仓空间恢复后整体重试）。

### 运行控制与失效（议题 8）

（用户 2026-09-07 确认）

- 标准 GTCEu 启停控制：软锤 + GUI 电源按钮；暂停期间不取汽、不推进，批次参数保留。
- 一般结构失效：进度回退 `1 tick`，修复后续跑原批次。
- 无特殊清空关键部位；控制器被拆除仅损失偏好配方 ID 与待输出结果（物品掉落，流体丢失）。
- 区块卸载持久化续跑，不补算离线进度；新注册机器无旧存档迁移问题。

### 蒸汽进气室接入（议题 12）

（用户 2026-09-08 确认：接受接入，且**每台最多 `1` 个**；本节含 💡 建议默认值与待定项）

#### 背景与理由

- 蒸汽时代没有电力气体收集器，`gtceu:centrifuge` 的 `air_separation`（空气 `10,000 mB` → 氮 `3,900` + 氧 `1,000`，`1,600 tick`，`EUt = VA[ULV] = 8`）在纯蒸汽阶段**只能靠蒸汽进气室供料**：GTCEu 标准流体输入仓单仓 `8,000 mB`（4X/9X 更小）装不下一份 `10,000 mB` 的空气，本模组蒸汽流体输入仓 `16,000 mB` 也只能支撑并行 `1`。
- 双机因此成为**蒸汽进气室的首个可玩消费者**（锅炉房仍在设计中未实现，此前该资产无合法消费者）。

#### 实现口径（✅ 已于 2026-09-08 实现）

#### 数值核算（`air_separation`，执行时长 `ceil(1600 × 1.5) = 2,400 tick` = `120 s`）

| 约束 | 上限来源 | 并行 |
| --- | --- | ---: |
| 空气输入 | 进气室 `64,000 / 10,000`（并行按单仓取 max，**不跨仓累加**） | `6` |
| 氮输出（标准 1X 仓 `8,000 mB` 单槽） | `8,000 / 3,900` | `2` |
| 氮输出（本模组蒸汽流体输出仓 `16,000 mB`） | `16,000 / 3,900` | `4` |
| 氧输出（标准 1X 仓 `8,000 mB`） | `8,000 / 1,000` | `8` |
| 机型上限 | 小型 `8` / 大型 `64` | — |

- **实际并行 = min(上述各项)**，且两种产物各需**独立单槽仓**（单槽只容一种流体）。
- 推荐配置与稳态（进气室 `50 mB/t` 供料）：

| 配置 | 输出仓 | 并行 | 空气需求 | 产氧 | 蒸汽 |
| --- | --- | ---: | ---: | ---: | ---: |
| 最简 | 标准 ×`2`（氮/氧各一） | `2` | `8.3 mB/t` | `0.83 mB/t` | `32 mB/t`（批 `76,800 mB`） |
| 进阶 | 蒸汽流体输出仓 `16 B` 装氮 + 标准 ×`1` 装氧 | `4` | `16.7 mB/t` | `1.67 mB/t` | `64 mB/t`（批 `153,600 mB`） |
| 上限 | 蒸汽流体输出仓 ×`2` 装氮 + 任意仓装氧 | `6` | `25 mB/t` | `2.5 mB/t` | `96 mB/t`（批 `230,400 mB`） |

- 接口预算核对：小型机 `1` 输入总线 + `1` 输出总线 + `1` 供给仓 + `1` 流体输入仓 + `1` 进气室 + `3` 输出仓 = `8` ✓（刚好达成理论上限 `6`）；大型机同配置 `+1` 排气仓 = `9 ≤ 12` ✓。
- 供汽：单供给仓上限 `1,200 mB/t`，三档配置均 `1` 个即可。
- 稳态余量：空气需求最高 `25 mB/t` < 进气室 `50 mB/t`，可长期连续运行；多装进气室**不提升并行**（并行取单仓 max），只是缩短等料——与「最多 `1` 个」无冲突。
