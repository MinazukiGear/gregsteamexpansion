### 类型范围与分工边界（议题 2）

（用户 2026-09-07 确认）

- **仅执行 `gtceu:centrifuge`（通用离心分离）类型**；`thermal_centrifuge`（热离心）类型不执行——矿石的“粉碎矿 → 离心粉碎矿”路线继续归上游热离心机，本机不接管。
- 与 GCYM 大型离心机（`large_centrifuge`，电力多方块，执行同一类型）按能源形态分层共存，保持上游原样。
- 与既有机器分工：本机是通用分离/流体处理的规模化设备；`centrifuge` 类型配方中的“纯净矿粉 → 粉尘”等分离路线归本机（A4 执行的 `macerator` 不含此配方）。
- 越级模式沿用：离心机属 LV 电力机器，越级使用、以蒸汽消耗为平衡代价、电力路线原样保留。

### 配方执行细节（议题 3）

（用户 2026-09-07 确认）

- 执行 `gtceu:centrifuge` 类型全部配方（外部模组新增配方同规则），基准数值不修改（类型默认 `EU/t = 5`、无默认耗时，按配方自带数值计算）。
- **电压门：仅可执行电压等级 ≤ LV 的配方**（含 ULV；同上游蒸汽单方块机器的等级限制行为）——MV 及以上的离心配方在本机不可运行；外部模组配方同受此门约束。
- 流体输出（类型最多 `6` 个流体输出槽）：产物经流体输出仓导出——可为 **GTCEu 标准输出仓或本模组蒸汽流体输出仓**，可选或混用（用户 2026-09-07 补充确认，B4 口径）；流体输入（类型最多 `1` 槽）按配方声明原样兼容，输入仓选型沿用 B4 口径（GTCEu 标准流体输入仓或本模组蒸汽流体输入仓均可）。
- 编程电路随物品输入总线进入（如配方要求），逐批按配方语义处理。

### 动力与蒸汽消耗（议题 5）

（用户 2026-09-07 确认）

- 仅接受 GTCEu 标准蒸汽，不消耗 EU；蒸汽换算率 `2 mB = 1 EU`。
- 执行时长为配方基准耗时乘固定倍率 `1.5×`：`max(1, ceil(基准耗时 × 1.5))` tick（`centrifuge` 无默认耗时的配方按自带数值计算）；单份总耗汽 = `配方 EU/t × 执行时长 × 2` mB。
- 能耗口径沿用粉碎机家族的**固定线性**：批次总耗汽与每刻需求按实际并行 `P` 线性放大（不用 B1/B2 次线性阶梯）。
- 断供蒸汽：进度回退至 `1 tick`，恢复后续跑原批次；排气受阻冻结进度，与缺气回退明确区分。
- 多供给仓不提高并行或效率；每仓 `1,200 mB/t` 机器侧上限沿用。

### 并行与吞吐（议题 6）

（用户 2026-09-07 确认）

- 蒸汽离心机最大并行固定 `8`；大型蒸汽离心机最大并行固定 `64`（粉碎机家族先例）。
- 实际并行 = `min(各自上限, 可用输入份数, 最坏情况输出可容纳份数)`；输出预检含最多 `6` 个物品输出位与 `6` 个流体输出位的全命中预留；公式小于 `1` 不开工、不扣取；批次开始后锁定。
- 耗时不随并行倍增；批次总耗汽与每刻需求按 `P` 线性放大。
- 配方选择沿用“最近成功配方优先”（首扫按输入槽编号，多匹配按资源 ID 字典序；偏好配方持久化，缺输入重扫、输出不足等待不改选）。

### 内部库存与批处理原子性（议题 7）

（用户 2026-09-07 确认）

- 沿用 S1/B1 口径：控制器缓存仅待输出结果，无内部物品槽与内部流体罐；全部库存由仓室直接承载。
- 开工预检跨全部仓室聚合执行：物品输入、流体输入份数与最坏情况输出（`6` 物品位 + `6` 流体位全命中预留）一次预检；通过后一次原子扣取全部输入。
- 产物提交：物品写入物品输出总线，流体写入流体输出仓（分别提交）；待输出保险沿用（异常时完整物品结果持久化于控制器，流体结果与输出仓空间恢复后整体重试）。

### 运行控制与失效（议题 8）

（用户 2026-09-07 确认）

- 标准 GTCEu 启停控制：软锤 + GUI 电源按钮；暂停期间不取汽、不推进，批次参数保留。
- 一般结构失效：进度回退 `1 tick`，修复后续跑原批次。
- 无特殊清空关键部位；控制器被拆除仅损失偏好配方 ID 与待输出结果（物品掉落，流体丢失）。
- 区块卸载持久化续跑，不补算离线进度；新注册机器无旧存档迁移问题。

### 表现与信息（议题 9）

（用户 2026-09-07 确认）

- GUI/Jade 整体沿用粉碎机已实现骨架：主状态、配方与进度、实际并行与上限（`8` / `64` 各按机型）、蒸汽合计存量与容量、每刻需求、待输出摘要；服务端权威同步。
- 进度条与声效沿用类型自带样式（离心/热离心进度条皮肤；本机仅 `centrifuge` 样式与声效）；配方实际推进时叠加旋转离心粒子。
- 控制器正面空闲/工作两态纹理走 `steamMultiblockModel` 的 `addTextureOverride` 模式。
- 两级物品提示（默认摘要 + Shift 完整说明）；文本优先复用既有资源，中英双语。

## 立项前提

1. **双机模式**：对照粉碎机家族（一份设计文档、两台机器、共用抽象基类）。
2. **定位**：通用离心分离的规模化设备（仅 `centrifuge` 类型 + LV 门）；热离心矿石路线保留上游。
3. **与 GCYM 大型离心机分层共存**：电力多方块保持上游原样（B4/GCYM 先例）。
4. **越级模式沿用**：LV 电力机器越级使用，蒸汽消耗为平衡代价。
