## 四、推荐顺序（本版）

1. **C1b 大型蒸汽提取机（推荐首选）**：橡胶链直接支撑已收口的 B1/B2（两者的结构与控制器配方消耗大量橡胶片），规模化上位模式第三次套用，类型极简且带流体输出槽（可顺带裁定蒸汽流体输出仓归宿）。
2. **C1a 大型蒸汽压缩机**：与 C1b 同族同模式，可紧随其后甚至成对立项（对照 B1/B2 双机模式）。
3. **B6 大型蒸汽锻压厂**：最轻、最无争议，适合作为节奏调剂。
4. **B3 大型蒸汽搅拌机**：需先与合金炉、浸洗厂谈清混合语义，建议放在实现阶段开启之后。
5. **C5a / C5b / C4**：需进一步核验配方生态或燃料链讨论，暂列观察。
6. **远期**：C2 蒸馏（MV 语义重）、C3 煤焦油处理（热解炉门控）。

| 高炉 / 原始高炉 | 与 GTCEu 上游同语义机器重复（高炉上位变体另见第三节暂缓项） |

| 无限水源类机器（含 ~~B5 蒸汽抽水站~~） | 原版水源机制已可作为无限水来源（B5 于 2026-09-07 经用户裁定撤销） |
| ~~A5 蒸汽煤气发生炉~~ | 煤气在热解炉之前不应有获取途径（进度门控，用户裁定 2026-09-07 撤销）；煤气类内容未来挂接热解炉时代再议 |

| 高级终端（原 C6） | 已撤销（2026-09-06）：GTM Things 高级终端承接该需求 |

## 六、任何一台机器立项时必须补齐的内容

按 `items-and-blocks.md` 的"新条目准入条件"与 `difficulty.md` 的"全局设置接入规则"，每台新机器在转入已确认状态前必须写明：

1. 中文名、英文名、资源 ID、注册字段、机器类、科技阶段；
2. 配方类型与槽位（物品/流体输入与输出各几槽）；
3. 结构尺寸、固定核心位置、可替换接口及各接口的精确数量上下限；
4. 并行公式、处理时间、蒸汽换算率与每刻需求；
5. 至少要求哪些孤儿资产，以及为什么不能复用 GTCEu 现有内容；
6. `Easy / Normal / Expert` 三档中受控字段的具体值（控制器恒为 `1` 个产出）；
7. 与已实现机器的复用关系（是否继承抽象基类）；
8. 验收清单（由用户执行，不得由助手代跑）。
