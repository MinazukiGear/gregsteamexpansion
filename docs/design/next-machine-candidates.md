## 七、新识别的可实现方向（2026-09-07 分析）

对照 GTCEu 全部加工类型与蒸汽机器清单（蒸汽单方块仅：锅炉 ×3、提取机、研磨机、压缩机、锻造锤、熔炉、合金炉、岩石破碎机），以下工序**仍无任何蒸汽途径**，均为可实现方向：

### 轻量 C 系补完（骨架现成，设计量最低）

| 机器 | 类型槽位 | 价值 |
| --- | --- | --- |
| 蒸汽拉线机 | `wiremill`（2 入 1 出，干式） | 线材（杆→线），**B2 电路链直接上游** |
| 蒸汽切割机 | `cutter`（1 入 2 出 + 1 流体入切削液） | 细导线、板/杆切割；**B2 电路链上游**；流体输入仓 B4 口径 |
| 蒸汽折弯机 | `bender`（2 入 1 出，干式） | 板/杆弯件、机械零件 |
| 蒸汽成型机 | `forming_press`（6 入 1 出，含 FormingPressLogic 模具逻辑） | 模具成型（需评估自定义逻辑） |
| 蒸汽包装机 / 拆包机 | `packer` / `unpacker`（各 2 入 2 出，默认 12EUt/10t） | 装箱、拆箱 |

### 流体/晶体化学线（中等，需一次“蒸汽时代化学深度”讨论）

| 机器 | 类型槽位 | 价值 / 风险 |
| --- | --- | --- |
| 蒸汽固化机 | `fluid_solidifier`（流体→物品，铸造语义） | 流体成型 |
| 蒸汽蒸馏器 | `distillery`（1/1/1/1） | 流体分馏 |
| 蒸汽流体加热器 | `fluid_heater`（1/0/1/1） | 流体加热 |
| 蒸汽高压釜 | `autoclave`（2/2/1/1） | 晶体培养（越级幅度较大） |

### 重化学线（门控风险高，暂缓级）

蒸汽化学反应釜（`chemical_reactor`）、蒸汽电解器（`electrolyzer`）、蒸汽极化器（`polarizer`）——化学/电解是 LV 时代的核心能力，越级幅度类似“煤气门控”问题，建议远期单独讨论。

### 旗舰新系统（非既有类型，高价值高设计量）

## 六、任何一台机器立项时必须补齐的内容

按 `items-and-blocks.md` 的"新条目准入条件"与 `difficulty.md` 的"全局设置接入规则"，每台新机器在转入已确认状态前必须写明：

1. 中文名、英文名、资源 ID、注册字段、机器类、科技阶段；
2. 配方类型与槽位（物品/流体输入与输出各几槽）；
3. 结构尺寸、固定核心位置、可替换接口及各接口的精确数量上下限；
4. 并行公式、处理时间、蒸汽换算率与每刻需求；
5. 至少要求哪些孤儿资产，以及为什么不能复用 GTCEu 现有内容；
6. `Easy / Normal / Expert` 三档中受控字段的具体值（控制器恒为 `1` 个产出）；
7. 与已实现机器的复用关系（是否继承抽象基类）；
8. 验收清单（由用户执行，不得由助手代跑）。
