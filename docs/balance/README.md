# P1 成长路线与经济基线

本轮范围为玩家成长路线、三档默认经济比较和自动化文档校验。根据用户指示，不设计供汽调度内容；不执行新的人工验收，也不修改已有数值定案。

- [玩家成长指南](../guides/steam-progression.md)：基础产汽、钢铁加工、大型工厂、模块扩建和后期升级。
- [经济基线](steam-economy.md)：默认三档及关闭难度的批次成本、产能、直接获取材料、预热/维护/复位与收益边界。
- [精确模型数据](steam-economy.json)：有理数、条件配方及来源指纹，便于后续比较参数和实际运行记录。

生成器为 [`tools/export_steam_economy.py`](../../tools/export_steam_economy.py)，仅使用 Python 标准库。`--check` 验证报告是否匹配当前来源；`checkSteamEconomy` 已接入 Gradle `check`，本地完整门禁与 CI 构建都会检查。公式签名改变时会先失败，需复核模型后再生成。

## 已明确的经济取舍

| 机制 | 本轮核对结论 | 使用方向 |
| --- | --- | --- |
| Expert 电路专精 | 默认期望产出 1.25 倍、耗时 1.5 倍；单位蒸汽增加 20%，期望产能降低约 16.7% | 保留省原料的定位，材料紧缺时启用 |
| 高炉高装料 | 满载两批加复位后，理论持续产能与普通 96 并行相同；复位仍耗资源 | 集中出货，安排好第二批输入 |
| 热风模块 | 同样普通批次交替蓄热/放热时，平均节汽约 7.5% | 长期稳定配方受益，避免把单批 15% 当持续优惠 |
| 大型仓超频 + 高效排气 | 偶数耗时名义单位蒸汽约 1.005 倍 | 提高产能，需更大瞬时供汽 |
| 流体钻井 | 默认 Expert 满速理论产量每小时 1,440 桶；总产物不能直接视为燃料 | 分别处理油气，核验返供白名单与净收益 |
| 最大蓄热熔炉 | 满温加工优惠与高启动投资同时存在 | 用长周期产量摊销启动和补热 |

以上整理现有规则，不构成新的平衡改动。此前钻井文档将 `20 mB/t` 换算为每小时 `72,000 mB`，本轮已更正为 `1,440,000 mB`，未改变机器代码。

## 后续验证边界

自动报告反映理想批次结算；生存采购、跨机器供汽、停机、客户端界面和整合包附加配方仍需实际运行记录。完整造价包含结构和接口，不能只用控制器材料。回本需定义材料估值与实际负载，报告给出计算条件，不填写假定回本时间。
