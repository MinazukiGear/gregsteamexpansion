# 蒸汽工厂成长指南

适用版本：`0.1.0-beta.2`（预发布），GTCEu Modern `7.5.3`。路线为“青铜加工与基础产汽 → 原始高炉首批钢 → 高压产汽与粉碎 → 大型工厂 → 模块扩建 → 后期蒸汽升级”。这是依据当前实现整理的建设指南；本轮人工验收已由使用者确认完成，自动化首批钢、配方核验及人工结果见[生存路线核验记录](../releases/beta2-progression-acceptance.md)。

各阶段先解决连续原料、供汽和输出，再扩大并行。三档默认材料、批次与启动成本见[经济基线](../balance/steam-economy.md)。整合包改动配方或参数时，以服务器配置和配方查看器为准。难度集成默认关闭，关闭时不能直接照搬 Normal 的产汽和产出倍率。

## 1. 基础产汽

先完成上游青铜蒸汽加工链与普通焦炉，建立焦炭和杂酚油来源，再按需要制作低压混合燃料锅炉。其控制器需要上游固体、液体两台低压锅炉；协同燃烧还要持续补充允许的粉料。液体燃料是否可用，以 `steam_boiler` 类型配方为准。

合成站适合反复制作零件和补位工具。青铜构件、研磨/搅拌等核心方块及工业蒸汽机械方块用于后续结构；Expert 会增加双层板等材料，Easy 的部分结构方块一次产出更多。按当前档位计算完整蓝图材料，并在查看器中比较手工与电力组装路线。

普通蒸汽供给仓提供机器取汽入口。增加仓数前，确认锅炉、管道和相邻容器能持续送入足够蒸汽；仓容量只提供缓冲。大型蒸汽储罐可缓存蒸汽，也不会增加锅炉的持续产量。

默认关闭难度时，满温 HP 混合锅炉协同产汽为 `60 mB/t`；Normal 为 `300 mB/t`。普通配置的粉碎机单并行需求为 `200 mB/t`：只按理想持续产量比较，关闭难度至少需要四台前述 HP 锅炉，Normal 一台即可覆盖。

供油必须同时核算：当前普通焦炉每 `900 tick` 将一块煤转为一块焦炭和 `500 mB` 杂酚油；HP 混合锅炉每 `175 tick` 消耗 `250 mB` 杂酚油。四台 HP 的理想耗油约 `114.29 mB/s`，至少需要 11 台上述普通焦炉持续供油；Normal 的一台 HP 至少需要三台。该下限假设 20 TPS、无批次间隔、无阻塞且不分流杂酚油，不包含粉料、水和管网限制。库存能支撑短批次，不能证明长期闭环；首次粉碎验收先按一并行记录供给和停机原因，再决定扩建。

进入下一阶段的条件：基础金属和工具可连续补给，机器能完成连续批次，燃料、水与输出不积压。规格见[机器与部件](../design/machines-and-hatches.md)、[混合锅炉](../design/mixed-fuel-boiler.md)和[焦炉体系](../design/coke-ovens.md)。

## 2. 钢铁加工

第一批钢来自上游原始高炉。大型蒸汽高炉控制器本身需要原始高炉、钢砖外壳和双层钢板，不能用它跳过最初炼钢。取得钢后，可升级高压产汽设备，再按零件和原料瓶颈选择蒸汽锻压、压缩、提取与矿物处理设备。

粉碎机也在首批钢之后：其控制器需要高压蒸汽研磨机和钻石研磨头；上游前者需要钢板，后者需要双层钢板。钢前的粉料和矿物处理先用上游青铜加工链。原始高炉的一铁锭加两木炭路线本身不耗蒸汽或电力，配方耗时 `1,800 tick`（20 TPS 下 90 秒），不用等待 GSE 粉碎机供汽线建成。

大型蒸汽高炉接替大宗锻铁和炼钢时，除配方内的固体燃料，还需蒸汽与鼓风。按实际并行配置供汽仓、空气进气室、物品输入/输出及排气；需求见[高炉经济表](../balance/steam-economy.md#高炉熟练度热风与高装料)。同一配方可积累熟练度，换配方 ID 后重新起算，适合按产品分线或集中排产。

进入下一阶段的条件：钢、燃料和鼓风稳定供给，常用配方可持续运行。规格见[大型蒸汽高炉](../design/large-steam-blast-furnace.md)。

## 3. 大型工厂

| 当前需求 | 优先考虑 | 扩建前检查 |
| --- | --- | --- |
| 大宗熔炼、合金加工 | 蓄热蒸汽熔炉 | 冷启动投资、长期供料量、对应模式温度门槛 |
| 矿物收益和副产物 | 粉碎、洗矿、热力离心、研磨或化学浸洗链 | 矿物实际配方、流体和副产物出口，避免只扩建最后一道机器 |
| 零件组装 | 大型蒸汽组装机 | 槽内电力组装机等级与数量、配方流体 |
| 电路原料紧缺 | 大型蒸汽电路组装机 | 电路槽、焊料、专精目标与最高增产的输出空间 |
| 多台设备争用蒸汽 | 对应材料级别锅炉房 | 液体燃料、协同粉料、水、鼓风、排气和维护链 |

组装机结构可先建成；控制器槽空时仅允许 ULV，装入对应 LV–EV 电力机器才解锁该等级配方。同种机器在单槽堆叠会提高并行，输入、焊料或输出空间不足时，实际并行仍会降低。

电路专精样品不消耗。默认 Easy、Normal 下可同时改善期望产能和单位蒸汽效率；Expert 下以更多时间和蒸汽换取更少目标电路原料，适合材料受限场景。没有持续缺料时，不应默认所有电路线都开专精。

蓄热熔炉从能长期供料的尺寸开始。最大结构的满温速度和加工折扣更强，也需更多启动蒸汽；短期小批量难以摊薄预热投资。取整示例见[熔炉启动成本](../balance/steam-economy.md#蓄热熔炉启动成本与摊销)。

## 4. 模块扩建

主机可连续运行后，再按场地与需求选择已有外挂。当前已实现高炉两项、锅炉房九项、大型焦炉两项；[外挂设计库](../design/large-machine-external-modules.md)中其他候选概念不代表已有功能。检查主体专属槽位、互斥关系、专用接口和实例归属。

高炉热风模块轮换蓄热、放热批次；同样批次长期交替时，平均节省约为优惠批次的一半。高装料用于集中出货，两个生产批次后还有消耗蒸汽和鼓风的复位阶段，持续产能不能按瞬时双倍并行计算。

终端多人施工共享全服预算，暂停工程会让出未使用的额度。目标页或预览页可取消当前队列：已完成目标保留，当前目标按归属日志安全回滚；空间不足的退款保存在“领取返还物”中。取消前应留意提示范围，拆除模式已拆下的方块不会自动重建。

锅炉房按维护负担选择模块。水垢会减产，到达报废阈值后不能继续使用；基础冷酸洗需稀盐酸、停炉冷却、清洗和重新升温。软化、清洗和回收模块可改善对应环节，其辅料及端口也要纳入生产线，不应只预留清洗动画时长。

终极终端需同时安装 AE2 与 GTM Things，可辅助建设、修复和拆除；可按安装面组合多个已实现外挂，同面互斥，施工前统一检查空间与材料。锅炉房可直接选择全部九项模块。仓室需自行安装；终端是可选工程工具，不是主机运行前置。

## 5. 后期蒸汽升级

获得 HV 电路后，可制作大型蒸汽供给仓和高效蒸汽排气仓。大型仓提高单仓缓存与取汽上限，并让支持的大型消费者可从下一批选择超频；高效排气降低正常生产的蒸汽需求。

普通节流保持批次总汽量，降低每刻需求并延长耗时。超频提高产能也增加单位蒸汽；高效排气与超频叠加后，偶数耗时的单位蒸汽约回到普通排气、不超频的水平。供汽受限时先用节流维持生产，持续供汽充足后再开超频。高装料有独立固定规则，不能套用普通超频和复位节汽假设。

虚空采矿厂和流体钻井用于解决长期、位置无关的资源需求，属于钢铁和供汽成熟后的旗舰投资。钻井的多种油气需分别存储、处理；返供锅炉由燃料白名单和炼化链决定，不能以总产量认定燃料闭环。默认天然气在蒸汽阶段先积累库存。产量与净收益口径见[钻井经济表](../balance/steam-economy.md#钻井与燃料闭环)。

## 建设前检查

- 用当前档位和蓝图计算整机材料，包含接口、槽位机器及可用工具；经济表中的控制器成本只是一部分。
- 用锅炉持续产量、管道送入量与消费者锁定需求核对供汽，单独保留启动和维护缓冲。
- 给产物、副产物安排出口；随机专精产物按最高产量预留容量。
- 比较完整生产/维护周期，把预热、冷却、酸洗、复位和随机产出计入平均收益。
